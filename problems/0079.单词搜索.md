# LeetCode 79. 单词搜索（Word Search）

> **题目链接**：[LeetCode 79. Word Search](https://leetcode.com/problems/word-search/)

---

## 题目描述

给定一个 `m x n` 的二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。

单词必须按照字母顺序，通过**相邻的单元格**内的字母构成，其中"相邻"单元格是那些**水平相邻或垂直相邻**的单元格。**同一个单元格内的字母不允许被重复使用**。

### 示例

```
输入：board = [
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
], word = "ABCCED"
输出：true
```

```
输入：board = [
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
], word = "SEE"
输出：true
```

```
输入：board = [
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
], word = "ABCB"
输出：false
```

### 数据范围

- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

---

## 解题思路

### 核心方法：DFS + 回溯（Backtracking）

这是一道经典的**深度优先搜索 + 回溯**问题。我们需要在二维网格中从任意起点出发，沿着上下左右四个方向探索，寻找一条路径使得路径上的字符按顺序拼接等于目标单词。

### 整体思路

1. **枚举起点**：遍历网格中每一个格子，如果该格子的字符与单词首字母匹配，则以它为起点开始 DFS 搜索。
2. **DFS 搜索**：从当前格子出发，向四个方向递归探索下一个字符。
3. **标记访问**：为了避免重复使用同一个单元格，需要记录哪些格子已经被访问过。
4. **回溯**：当某条路径走不通时，撤销访问标记，回到上一层继续尝试其他方向（这就是回溯的核心）。

### 为什么需要回溯？

因为 DFS 是一条路走到黑的策略，当某条路径走不通时，我们需要**撤销之前的选择**（恢复访问标记），然后尝试其他方向。如果不回溯，那些被标记为"已访问"但实际上不在正确路径上的格子会永远无法被其他路径使用，导致漏解。

### 访问标记的两种实现方式

| 方式 | 说明 | 空间复杂度 |
|------|------|-----------|
| 额外 visited 数组 | 开一个二维布尔数组记录访问状态 | O(m×n) |
| **原地修改棋盘** | 递归前将当前字符改为特殊占位符（如 `'#'`），递归结束后恢复原值 | **O(1)**（不计递归栈） |

原地修改的方式更优，不需要额外空间。

## 算法步骤

### DFS 函数设计

**函数签名**：
```cpp
bool dfs(board, word, x, y, idx)
```

**参数含义**：
- `board`：二维字符网格（注意传引用，且需要可修改）
- `word`：目标单词
- `x, y`：当前所在格子的坐标
- `idx`：当前正在匹配的单词字符的索引

**返回值**：从 `(x, y)` 出发，能否匹配单词从 `idx` 开始的后缀。

### DFS 执行流程

```
dfs(board, word, x, y, idx):
    1. 如果当前格子字符 != word[idx]，返回 false
    2. 如果 idx == word.size() - 1，说明已匹配到最后一个字符，返回 true
    3. 保存当前格子的原始字符，将其改为 '#'（标记已访问）
    4. 遍历四个方向：
       - 计算新坐标 (nx, ny)
       - 如果越界或已访问（值为 '#'），跳过
       - 递归调用 dfs(board, word, nx, ny, idx + 1)
       - 如果递归返回 true，直接向上返回 true（找到解了）
    5. 恢复当前格子的原始字符（回溯）
    6. 四个方向都失败，返回 false
```

### 主函数流程

```
exist(board, word):
    遍历每一个格子 (i, j):
        如果 dfs(board, word, i, j, 0) 返回 true:
            返回 true
    所有起点都试过了，返回 false
```

## 代码实现

```cpp
class Solution {
    // Direction vectors: up, right, left, down
    static constexpr int dir[4][2] = {{-1, 0}, {0, 1}, {0, -1}, {1, 0}};

    /**
     * @brief DFS with backtracking to find word starting from (x, y) at index idx
     * @param board 2D character grid (modified in-place for visited marking)
     * @param word  Target word to search for
     * @param x     Current row index
     * @param y     Current column index
     * @param idx   Current character index in word
     * @return true if the suffix word[idx..end] can be found from (x, y)
     */
    bool dfs(vector<vector<char>>& board, const string& word, int x, int y, int idx) {
        // Step 1: Check if current cell matches the target character
        if (board[x][y] != word[idx]) {
            return false;
        }

        // Step 2: Base case - reached the last character, word found
        if (idx == word.size() - 1) {
            return true;
        }

        // Step 3: Mark current cell as visited by replacing with a placeholder
        char origin = board[x][y];
        board[x][y] = '#';

        // Step 4: Explore all four directions
        for (int k = 0; k < 4; ++k) {
            int nx = x + dir[k][0];
            int ny = y + dir[k][1];

            // Skip if out of bounds
            if (nx < 0 || ny < 0 || nx >= board.size() || ny >= board[0].size()) {
                continue;
            }
            // Skip if already visited
            if (board[nx][ny] == '#') {
                continue;
            }
            // If this direction leads to a valid solution, propagate true upward
            if (dfs(board, word, nx, ny, idx + 1)) {
                return true;
            }
        }

        // Step 5: Backtrack - restore the original character
        board[x][y] = origin;

        // Step 6: All directions failed
        return false;
    }

public:
    bool exist(vector<vector<char>>& board, string word) {
        int n = board.size();
        int m = board[0].size();

        // Try each cell as the starting point
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (dfs(board, word, i, j, 0)) {
                    return true;
                }
            }
        }
        return false;
    }
};
```

## 复杂度分析

### 时间复杂度：O(m × n × 3^L)

- `m × n`：枚举起点的数量
- `L`：单词的长度（即递归深度）
- `3^L`：每个格子除了来的方向，有 3 个新方向可以走，递归深度为 L

> 为什么是 3^L 而不是 4^L？因为每个格子有 4 个方向，但其中一个方向是来的路（已访问），所以实际只有 3 个新方向可选。

### 空间复杂度：O(L)

- 递归栈的最大深度为单词长度 L
- 原地修改棋盘标记访问，不需要额外的 visited 数组
- 因此空间复杂度主要由递归栈决定，为 O(L)

## 常见错误与陷阱

### 错误 1：没有访问标记（最常见）

**问题**：不记录已访问的格子，导致同一个单元格被重复使用。

```cpp
// 错误示例：没有访问标记
bool dfs(...) {
    if (board[x][y] != word[idx]) return false;
    if (idx == word.size() - 1) return true;
    for (四个方向) {
        if (dfs(nx, ny, idx + 1)) return true; // 可以走回头路！
    }
    return false;
}
```

**反例**：
```
board = [['A', 'B'],
         ['C', 'A']]
word  = "ABA"
```
错误代码会走出 `A(0,0) → B(0,1) → A(0,0)` 的路径，错误返回 `true`，但 A 被重复使用了。

### 错误 2：方向循环中直接 return，不回溯

**问题**：在 for 循环里写 `return dfs(...)`，导致第一个方向走不通就直接返回 false，不会尝试其他方向。

```cpp
// 错误示例：直接 return，不会尝试剩余方向
for (int k = 0; k < 4; ++k) {
    ...
    return dfs(board, word, nx, ny, idx + 1); // 错！第一个方向不行就直接放弃
}
```

**正确写法**：只有子递归返回 true 时才向上返回 true，否则继续循环尝试下一个方向。

```cpp
// 正确写法
for (int k = 0; k < 4; ++k) {
    ...
    if (dfs(board, word, nx, ny, idx + 1)) {
        return true; // 找到解才返回
    }
    // 没找到就继续试下一个方向
}
```

### 错误 3：终止条件顺序倒置

**问题**：先判断 `idx >= word.size()-1` 返回 true，再检查字符是否匹配。

```cpp
// 危险写法：先返回成功，再校验字符
if (idx >= word.size() - 1) return true;  // 先返回成功
if (board[x][y] != target) return false;  // 再检查字符
```

虽然在调用 dfs 前提前检查了字符的情况下暂时不会出错，但逻辑上是倒置的。如果后续代码修改漏了前置检查，会直接出现字符不匹配也返回 true 的 bug。

**正确顺序**：先校验字符，再判断是否到达末尾。

```cpp
if (board[x][y] != word[idx]) return false; // 先校验字符
if (idx == word.size() - 1) return true;    // 再判断是否完成
```

## 优化思路

### 优化 1：字符频次剪枝

在开始搜索前，先统计棋盘上每个字符的出现次数，以及单词中每个字符的出现次数。如果单词中某个字符的数量超过棋盘上该字符的总量，直接返回 `false`。

```cpp
// 剪枝：统计字符频次
int cnt[128] = {0};
for (auto& row : board)
    for (char c : row) cnt[c]++;
for (char c : word) {
    if (--cnt[c] < 0) return false; // 单词中该字符比棋盘还多，不可能
}
```

这个优化在单词较长或字符分布不均时效果显著。

### 优化 2：单词首尾交换

如果单词首字母在棋盘上出现的次数比尾字母多，可以将单词反转后再搜索。这样起点数量更少，搜索效率更高。

```cpp
// 如果首字母出现次数 > 尾字母出现次数，反转单词
if (count(word.begin(), word.end(), word.front()) >
    count(word.begin(), word.end(), word.back())) {
    reverse(word.begin(), word.end());
}
```

### 优化 3：提前终止（已实现）

一旦找到一条合法路径就立即返回 `true`，不需要继续搜索剩余的起点和方向。这在代码中已经体现。

## 总结

> 这道题我用 **DFS + 回溯** 的方法来解决。
>
> 首先，我遍历网格中的每一个格子作为起点，如果当前格子的字符和单词的首字母匹配，就从这个位置开始深度优先搜索。
>
> 在 DFS 的过程中，我用**原地修改棋盘**的方式来标记已访问的格子——递归前把当前字符改成一个特殊的占位符比如 `'#'`，递归结束后再恢复成原来的字符，这就是回溯的过程。这样做不需要额外的 visited 数组，空间复杂度更优。
>
> 每一步我会向上下左右四个方向探索，如果某个方向的字符匹配单词的下一个字符，就继续递归深入。如果某条路径能一直匹配到单词的最后一个字符，说明找到了，直接返回 true。如果四个方向都走不通，就回溯到上一层，尝试其他方向。
>
> 时间复杂度是 O(m×n×3^L)，其中 m 和 n 是网格的行列数，L 是单词长度。因为每个格子有 3 个新方向可以选（排除来的方向），递归深度是 L。空间复杂度是 O(L)，主要是递归栈的开销。
>
> 另外还可以做一些优化，比如提前统计字符频次做剪枝，如果单词里某个字符的数量超过棋盘总量就直接返回 false，能过滤掉很多不可能的情况。
