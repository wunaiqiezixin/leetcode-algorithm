# [Corporate Flight Bookings](https://leetcode.cn/problems/corporate-flight-bookings/)

> 数据范围：`1 <= n <= 2*10^4`，`1 <= bookings.length <= 2*10^4`，每条 `bookings[i] = [first, last, seats]`，`1 <= first <= last <= n`，`1 <= seats <= 10^4`
>
> 题型：**差分数组（Difference Array）+ 前缀和**，区间批量加法的标准套路；暴力会超时，必须用差分把区间修改压成 O(1)

## 题目分析

有 `n` 个航班（编号 `1..n`），每份预订 `bookings[i] = [first, last, seats]` 表示在 `first..last`（**闭区间，含两端**）每个航班上都被预订了 `seats` 个座位。

求每个航班的总座位数，返回长度 `n` 的数组。

本质上是一个 **"区间加法 + 单点查询"** 问题：对 `m` 个区间 `[first, last]` 每个位置加 `seats`，最后问每个位置的值是多少。

## 为什么用差分数组（算法选型对比）

| 做法 | 思路 | 复杂度 | 能否过 |
|---|---|---|---|
| 暴力 | 每条预订直接循环 `for j in [first, last]: ans[j] += seats` | O(m · n) ≈ 4e8 | 最坏会超时 |
| 差分数组 | 只改两个端点，最后前缀和还原 | O(m + n) | ok! |

- `n, m` 都到 `2*10^4`，暴力最坏 `2e4 × 2e4 = 4e8` 次加法，危险。
- 差分把"区间加"退化成"两个端点的单点修改"，整体线性，稳过。

> 类比：评论区常说的"上下车模型"——`first` 时刻上车 `seats` 人，`last+1` 时刻下车 `seats` 人；最终每个时刻车内人数就是前缀和。

## 核心思想

构造**差分数组** `d`（长度开到 `n+2`，多留一位容纳 `last+1`）：

- `d[first] += seats`：从 `first` 开始，后面每个位置都"继承"这 `seats` 个增量。
- `d[last+1] -= seats`：到 `last` 结束，`last+1` 起这 `seats` 个增量"失效"。

然后做一次**前缀和** `d[i] += d[i-1]`，`d[1..n]` 就是每个航班的最终座位数。

**为什么正确**：差分的核心性质——`d` 的前缀和 `pref[i]` 等于"所有覆盖位置 `i` 的区间增量之和"。
- 区间 `[first, last]` 的 `seats` 对 `i ∈ [first, last]` 有贡献，对 `i > last` 无贡献。
- `d[first] += seats` 让前缀和从 `first` 起每步 +seats；`d[last+1] -= seats` 让前缀和从 `last+1` 起把这部分抵消掉。两者配合，恰好使 `seats` 只落在 `[first, last]`。

## 关键细节

1. **1-indexed → 数组下标**：题目中航班编号是 `1..n`，差分我直接按 `1..n` 建数组（长度 `n+2`），端点用原值 `first` / `last+1`，最后取 `d[1..n]`，避免频繁 `-1` 出错。也可以全部转 `0-indexed`（`l=first-1, r=last-1`，在 `d[l]+=seats; d[r+1]-=seats`，数组长度 `n+1`），两种等价。
2. **`last+1` 越界保护**：当 `last == n` 时 `last+1 == n+1`，所以数组必须开到 `n+2`（或 `0-indexed` 时开 `n+1` 并对 `r+1 < n` 才减）。开小一位会越界 / 漏减。
3. **前缀和顺序**：必须 `for i = 1..n: d[i] += d[i-1]`，从前往后累加，不能从后往前。

## 复杂度

- 时间：`O(m + n)` —— 扫一遍所有预订（m 次端点修改）+ 一次前缀和（n 次）。
- 空间：`O(n)` —— 差分数组 `n+2`。

## 易错点

1. **忘记 1-indexed 转换**：题目编号从 1 开始，直接用 `first`/`last` 当下标时要么整体按 1-indexed 建数组，要么统一 `-1` 转 0-indexed，混用必 WA。
2. **`last+1` 越界**：`last` 可能等于 `n`，减操作的位置 `n+1` 必须落在数组内（数组开 `n+2`），否则越界未定义 / 漏减导致该区间多算。
3. **溢出**：单航班最坏 `m × seats = 2e4 × 1e4 = 2e8`，仍在 `int` 范围内（≤ 2.1e9），用 `int` 即可；若担心更大数据可改 `long long`（LeetCode 本题返回 `vector<int>`，内部用 `int` 足够）。

## 完整代码（C++）

```cpp
class Solution {
public:
    vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
        // 1-indexed 差分数组，多开一位容纳 last+1
        vector<int> d(n + 2, 0);
        for (const auto& b : bookings) {
            int first = b[0], last = b[1], seats = b[2];
            d[first] += seats;        // 从 first 开始生效
            d[last + 1] -= seats;     // 到 last 结束，last+1 起失效
        }
        // 前缀和还原每个航班的实际座位数
        for (int i = 1; i <= n; ++i) d[i] += d[i - 1];
        return vector<int>(d.begin() + 1, d.begin() + 1 + n);
    }
};
```

## 一句话总结

区间批量加法 → **差分数组**：左端点 `+seats`、右端点 `+1` 处 `-seats`，最后前缀和还原；注意题目是 **1-indexed** 且 **`last+1` 可能越界要开 `n+2`**，复杂度 `O(m+n)`。
