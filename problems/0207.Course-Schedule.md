# [Course Schedule](https://leetcode.cn/problems/course-schedule/)

---

## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai` 则**必须**先学习课程 `bi`。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 0，你需要先完成课程 1。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

### 示例

```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0。这是可能的。
```

```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0；
     并且学习课程 0 之前，你还应先完成课程 1。这是不可能的。
```

### 数据范围

- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有先修对都是**互不相同**的

---

## 问题本质：有向图判环

这道题的本质是：**给你一个有向图，判断图中是否存在环**。

- 每门课程是一个**节点**
- 每条先修关系是一条**有向边**（从先修课指向后续课，或者反过来，取决于你怎么建图）
- 如果图中有环 → 课程之间循环依赖 → 不可能完成 → 返回 false
- 如果图中无环 → 存在拓扑排序 → 可以完成 → 返回 true

> **拓扑排序**：把有向无环图（DAG）的节点排成一个线性序列，使得对于任意一条边 u→v，u 都排在 v 前面。有环的图不存在拓扑排序。

---

## 方法一：BFS + 拓扑排序（Kahn 算法）

### 核心思路

利用**入度**来判断：每次选一个入度为 0 的节点（没有先修课的课），把它"拿走"，然后把它指向的节点的入度减 1。重复这个过程，如果最后所有节点都被拿走了，说明无环。

### 算法步骤

1. **建图**：用邻接表存储有向图，同时统计每个节点的入度
2. **初始化队列**：把所有入度为 0 的节点加入队列
3. **BFS 遍历**：
   - 从队首取出一个节点，计数 +1
   - 遍历它的所有邻接点，将每个邻接点的入度减 1
   - 如果某个邻接点的入度变成 0，加入队列
4. **判断结果**：如果计数 == 总节点数 → 无环 → true；否则 → 有环 → false

### 为什么入度为 0 就能选？

入度为 0 意味着这个节点**没有任何前驱依赖**，可以直接学习。学完之后，它的后继课程就少了一个先修条件（入度减 1）。当某门课的所有先修课都学完了（入度变成 0），它就可以学了。

### 代码实现

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        // adj[i] 存储课程 i 的所有后继课程（学完 i 之后才能学的课）
        vector<vector<int>> adj(numCourses);
        vector<int> inDegree(numCourses, 0); // 每门课的入度

        // 建图：[a, b] 表示要学 a 先学 b，即边是 b -> a
        for (const auto& p : prerequisites) {
            int a = p[0]; // 后续课程
            int b = p[1]; // 先修课程
            adj[b].push_back(a); // b -> a
            inDegree[a]++;       // a 的入度 +1
        }

        // 队列：存放入度为 0 的节点
        queue<int> q;
        for (int i = 0; i < numCourses; ++i) {
            if (inDegree[i] == 0) {
                q.push(i);
            }
        }

        while (!q.empty()) {
            int u = q.front();
            q.pop();
            numCourses--;
            // 遍历 u 的所有后继课程
            for (int v : adj[u]) {
                inDegree[v]--;       // 后继课程的入度减 1（少了一门先修课）
                if (inDegree[v] == 0) {
                    q.push(v);       // 入度为 0 了，可以学了，入队
                }
            }
        }

        // 如果学完的课程数 == 总课程数，说明全部能学完
        return numCourses == 0;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n + m)，n 是课程数，m 是先修关系数。每个节点入队出队一次，每条边遍历一次。
- **空间复杂度**：O(n + m)，邻接表和入度数组。

## 方法二：DFS 判环

### 核心思路

用 DFS 遍历图，给每个节点标记三种状态：

| 状态 | 含义 |
|------|------|
| 0 | 未访问过 |
| 1 | **正在访问**（在当前 DFS 递归栈中） |
| 2 | 已访问完成（整个 DFS 子树都遍历完了） |

如果在 DFS 过程中，遇到了一个**状态为 1** 的节点，说明我们沿着路径走回了一个"正在访问"的节点 → **存在环**。

### 为什么这样能检测环？

想象你在走迷宫，边走边在地上画箭头标记"我正在走这条路"。如果你走着走着发现前面有一个你刚画的箭头，说明你绕回来了——这就是环。

- 状态 1 就相当于"我刚走到这里，这条路还没走完"
- 状态 2 相当于"这条路走完了，是死胡同或者出口，没有环"

### 算法步骤

1. **建图**：邻接表存储
2. **初始化访问数组**：全为 0（未访问）
3. **对每个未访问的节点做 DFS**：
   - 标记当前节点为 1（正在访问）
   - 遍历所有邻接点：
     - 如果邻接点状态为 0 → 递归 DFS，如果返回 false（有环），直接返回 false
     - 如果邻接点状态为 1 → 遇到环了，返回 false
     - 如果邻接点状态为 2 → 已经处理过了，跳过
   - 标记当前节点为 2（访问完成）
   - 返回 true（这条路径无环）
4. **所有节点都 DFS 完了都没发现环 → 返回 true**

### 代码实现

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        // 建邻接表
        vector<vector<int>> adj(numCourses);
        for (const auto& p : prerequisites) {
            adj[p[1]].push_back(p[0]); // p[1] -> p[0]
        }

        // 0 = 未访问, 1 = 正在访问, 2 = 已访问完成
        vector<int> visited(numCourses, 0);

        // 对每个未访问的节点做 DFS
        for (int i = 0; i < numCourses; ++i) {
            if (visited[i] == 0) {
                if (!dfs(adj, visited, i)) {
                    return false; // 发现环
                }
            }
        }
        return true;
    }

private:
    /**
     * @brief DFS 检测以 u 为起点的路径是否有环
     * @param adj 邻接表
     * @param visited 访问状态数组
     * @param u 当前节点
     * @return 无环返回 true，有环返回 false
     */
    bool dfs(vector<vector<int>>& adj, vector<int>& visited, int u) {
        visited[u] = 1; // 标记为正在访问

        for (int v : adj[u]) {
            if (visited[v] == 0) {
                // 未访问过，递归深入
                if (!dfs(adj, visited, v)) {
                    return false;
                }
            } else if (visited[v] == 1) {
                // 遇到正在访问的节点 → 有环
                return false;
            }
            // visited[v] == 2 时直接跳过，已经处理过了
        }

        visited[u] = 2; // 标记为访问完成
        return true;
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n + m)，每个节点和每条边都只访问一次。
- **空间复杂度**：O(n + m)，邻接表 O(m)，访问数组 O(n)，递归栈最坏 O(n)。

## 两种方法对比

| 对比维度 | BFS + 拓扑排序 | DFS 判环 |
|---------|---------------|----------|
| 核心思想 | 入度为 0 就删，看能不能删完 | 走路径，遇到"正在访问"的节点就是环 |
| 空间结构 | 队列 + 入度数组 | 递归栈 + 状态数组 |
| 适用场景 | 需要输出拓扑序列时首选 | 只需要判环时也很方便 |
| 实现难度 | 较直观 | 需要理解三种状态 |
| 最坏栈/队列大小 | O(n) | O(n)（递归深度） |

> 两种都要掌握。BFS 写法更不容易出错（没有递归栈溢出的问题），DFS 代码更简洁。一般推荐先写 BFS。

## 常见坑点

### 坑 1：边的方向搞反

题目说 `prerequisites[i] = [ai, bi]` 表示学 `ai` 之前要先学 `bi`。

```
要学 a，先学 b  →  边是 b → a  →  入度加在 a 上
```

很多人搞反了，写成 `adj[a].push_back(b)`，结果就全错了。


### 坑 2：DFS 中忘记处理状态 2 的情况

状态 2 表示这个节点已经完整 DFS 过了，确认没有环。遇到状态 2 的节点直接跳过就行，不用再递归了。

```cpp
if (visited[v] == 0) {
    // 递归
} else if (visited[v] == 1) {
    // 有环
}
// visited[v] == 2 时什么都不做，直接跳过
```

### 坑 3：BFS 中只看入度不计数

有些人只判断最后队列空了就返回 true，这是不对的。必须统计出队的节点数，看是否等于总节点数。

因为如果图有多个连通分量，其中一个有环，其他没有，队列也会空，但不是所有节点都被访问过了。

```cpp
// 错误：队列空了就返回 true
while (!q.empty()) { ... }
return true;

// 正确：比较计数
return !numCourses;
```

### 坑 4：DFS 递归栈溢出

当图是一条很长的链（比如 2000 个节点连成一条线），递归深度会达到 2000，可能栈溢出。但这道题的数据范围 n <= 2000，一般不会有问题。如果 n 很大（比如 10^5），就必须用 BFS 了。

## 总结

>
> 这道题本质是**有向图判环**，有环就不可能完成所有课程，无环就可以。我可以用两种方法做。
>
> **第一种是 BFS + 拓扑排序（Kahn 算法）**：
> 先建图并统计每个节点的入度，然后把所有入度为 0 的节点加入队列。每次从队首取出一个节点，计数加一，然后遍历它的所有邻接点，把邻接点的入度减一，如果入度变成 0 就入队。最后如果计数等于总节点数，说明所有节点都能拓扑排序，也就是无环，返回 true。
>
> **第二种是 DFS 判环**：
> 给每个节点标记三种状态——0 表示未访问，1 表示正在访问（在递归栈中），2 表示已访问完成。对每个未访问的节点做 DFS，先标记为 1，然后遍历邻接点。如果邻接点状态是 0 就递归，如果状态是 1 说明遇到了环，直接返回 false。遍历完所有邻接点后标记为 2。如果所有节点都 DFS 完了都没发现环，就返回 true。
>
> 两种方法的时间复杂度都是 O(n + m)，空间也是 O(n + m)。BFS 的好处是没有递归栈溢出的问题，写法也比较直观；DFS 代码更简洁一些。
