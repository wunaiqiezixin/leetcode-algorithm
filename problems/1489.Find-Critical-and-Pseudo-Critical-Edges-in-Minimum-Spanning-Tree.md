
# [Find Critical and Pseudo-Critical Edges in Minimum Spanning Tree](https://leetcode.cn/problems/find-critical-and-pseudo-critical-edges-in-minimum-spanning-tree/)

---

## 题目描述

给你一个 `n` 个点的带权无向连通图，节点编号为 `0` 到 `n-1`，同时还有一个 `m` 条边的数组 `edges`，其中 `edges[i] = [from_i, to_i, weight_i]` 表示 `from_i` 和 `to_i` 之间有一条权值为 `weight_i` 的无向边。

**最小生成树（MST）** 是给定图中边的一个子集，它连接了所有节点且没有环，而且这些边的权值总和最小。

请你找到图中**所有的关键边和伪关键边**：

- **关键边**：如果从图中删去这条边，会导致最小生成树的权值和增加（或者无法形成最小生成树）。换句话说，**所有的 MST 都必须包含这条边**。
- **伪关键边**：**可能出现在某些 MST 中，但不会出现在所有 MST 中**的边。

返回 `ans`，其中 `ans[0]` 是所有关键边的编号（按原始输入顺序），`ans[1]` 是所有伪关键边的编号。

### 示例

```
输入：n = 5, edges = [
  [0,1,1],
  [1,2,1],
  [2,3,2],
  [0,3,2],
  [0,4,3],
  [3,4,3],
  [1,4,6]
]
输出：[[0,1],[2,3,4,5]]
```

解释：
- 关键边：边 0 和边 1（它们是所有 MST 都必须包含的）
- 伪关键边：边 2、3、4、5（它们可以出现在某些 MST 中，但不是必须的）
- 边 6 既不是关键边也不是伪关键边（它的权值太大，任何 MST 都不会选它）

### 数据范围

- `2 <= n <= 100`
- `1 <= m <= 200`
- `1 <= weight_i <= 1000`

---

## 核心概念理解

### 什么是关键边？

> **删掉它，MST 权值就变大（或者连不成 MST）。**

换句话说，**每一棵 MST 都一定包含这条边**。如果有一条边，你把它从图里抠掉，MST 的总权值就上升了，说明这条边是无可替代的——它就是关键边。

### 什么是伪关键边？

> **某些 MST 里有它，某些 MST 里没有它。**

也就是说，这条边**可以**出现在 MST 中，但不是必须的。当存在多条权值相同的边可以选时，选哪条都能得到同样权值的 MST，这些可替换的边就是伪关键边。



---

## 解题思路：纯 Kruskal + 并查集

这道题看起来很难，但如果你已经掌握了 **Kruskal 算法 + 并查集**，完全可以用**暴力枚举 + 验证**的思路做出来，不需要任何高级算法。

### 整体思路

1. **先算一遍标准 MST 的权值**，记为 `mst_val`
2. **枚举每一条边**，分别做两次 Kruskal 验证：
   - **删边验证**：删掉这条边，重新跑 Kruskal，如果 MST 权值变大或连不通 → 关键边
   - **强制加边验证**：如果不是关键边，就强制(优先)把这条边加进去，再跑 Kruskal，如果总权值还是 `mst_val` → 伪关键边

### 为什么这样判断是对的？

#### 判断关键边：删边法

> 如果删掉某条边后，MST 权值变大了，说明这条边是不可替代的 → 关键边

原理很简单：如果这条边不是必须的，那删掉它应该能找到其他权值相同的替代方案，MST 权值不变。只有当它是关键边时，删掉它才会导致权值上升。

#### 判断伪关键边：强制加边法

> 如果强制(优先)把某条边加入 MST，总权值仍然等于标准 MST 权值，说明这条边可以出现在某个 MST 中 → 伪关键边

原理：我们先把这条边的两个端点合并（相当于强制选了这条边），然后继续用 Kruskal 选剩下的边。如果最终总权值和标准 MST 一样，说明存在一棵包含这条边的 MST。

---

## 算法步骤

### 第一步：预处理边

因为 Kruskal 需要按权值排序，但最后要返回**原始索引**，所以我们给每条边加上它的原始编号：

```
原始边：[u, v, w]
处理后：[u, v, w, 原始索引]
```

然后按权值从小到大排序。

### 第二步：求标准 MST 权值

正常跑一遍 Kruskal，得到 `mst_val`。

### 第三步：枚举每条边，判断类型

对第 `i` 条边：

#### (1) 判断是否是关键边

```
初始化并查集
val = 0
cnt = 0
for 每条边 j（j != i）:
    if u 和 v 不在同一集合:
        合并
        val += w
        cnt++

if cnt != n-1 或 val > mst_val:
    → 关键边
```

#### (2) 如果不是关键边，判断是否是伪关键边

```
初始化并查集
val = 第 i 条边的权值
先合并第 i 条边的两个端点（强制选这条边）

for 每条边 j:
    if u 和 v 不在同一集合:
        合并
        val += w

if val == mst_val:
    → 伪关键边
```

## 完整代码实现

```cpp
class Solution {
private:
    // ===== 并查集模板（简单好用）=====
    static constexpr int MAXN = 101;
    vector<int> father = vector<int>(MAXN);

    void init() {
        for (int i = 0; i < MAXN; ++i) father[i] = i;
    }

    int find(int x) {
        return father[x] == x ? x : father[x] = find(father[x]);
    }

    void join(int u, int v) {
        u = find(u);
        v = find(v);
        if (u != v) father[v] = u;
    }

    bool same(int u, int v) {
        u = find(u);
        v = find(v);
        return u == v;
    }

public:
    vector<vector<int>> findCriticalAndPseudoCriticalEdges(int n, vector<vector<int>>& edges) {
        int m = edges.size();

        // ===== 第一步：给每条边加上原始索引，方便最后归类 =====
        vector<vector<int>> edgeList(m);
        for (int i = 0; i < m; ++i) {
            // edgeList[i] = [u, v, w, 原始索引]
            edgeList[i] = {edges[i][0], edges[i][1], edges[i][2], i};
        }

        // 按权值从小到大排序（Kruskal 标准操作）
        sort(edgeList.begin(), edgeList.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[2] < b[2];
        });

        // ===== 第二步：求标准 MST 的权值 =====
        init();
        int mst_val = 0;
        for (const auto& e : edgeList) {
            int u = e[0], v = e[1], w = e[2];
            if (!same(u, v)) {
                join(u, v);
                mst_val += w;
            }
        }

        vector<int> critical; // 关键边的原始索引
        vector<int> pseudo;   // 伪关键边的原始索引

        // ===== 第三步：枚举每条边，判断类型 =====
        for (int i = 0; i < m; ++i) {
            int originIdx = edgeList[i][3]; // 这条边的原始索引

            // ---------- (1) 判断是否是关键边：删掉这条边，重新跑 Kruskal ----------
            init();
            int val = 0;
            int edgeCnt = 0; // 统计加入了多少条边(用于判断图是否联通)
            for (int j = 0; j < m; ++j) {
                if (j == i) continue; // 跳过第 i 条边（模拟删除）
                int u = edgeList[j][0], v = edgeList[j][1], w = edgeList[j][2];
                if (!same(u, v)) {
                    join(u, v);
                    val += w;
                    edgeCnt++;
                }
            }
            // 删边后无法连通所有节点，或者 MST 权值变大 → 关键边
            if (edgeCnt != n - 1 || val > mst_val) {
                critical.push_back(originIdx);
                continue; // 关键边不可能是伪关键边，直接跳过下一轮判断
            }

            // ---------- (2) 判断是否是伪关键边：强制加入这条边，再跑 Kruskal ----------
            init();
            val = edgeList[i][2];                    // 先加上这条边的权值
            join(edgeList[i][0], edgeList[i][1]);    // 先把两个端点合并（强制选这条边）
            for (int j = 0; j < m; ++j) {
                int u = edgeList[j][0], v = edgeList[j][1], w = edgeList[j][2];
                if (!same(u, v)) {
                    join(u, v);
                    val += w;
                }
            }
            // 强制加边后权值仍然等于 mst_val → 伪关键边
            if (val == mst_val) {
                pseudo.push_back(originIdx);
            }
        }

        return {critical, pseudo};
    }
};
```

## 复杂度分析

### 时间复杂度：O(m² · α(n))

- 排序：O(m log m)
- 标准 Kruskal：O(m · α(n))
- 枚举每条边做两次 Kruskal：O(m × 2m · α(n)) = O(m² · α(n))
- m 最大 200，m² = 40000，完全可以轻松通过

### 空间复杂度：O(n + m)

- 并查集数组：O(n)
- 存储带索引的边：O(m)

## 常见坑点

### 坑 1：忘记记录原始索引

Kruskal 需要排序，但最后返回的答案要求是**原始输入中的边的编号**。如果排序后忘了记录原始索引，最后就不知道哪条边对应哪个编号了。

**解决方法**：给每条边多加一个字段存原始索引。

### 坑 2：删边后只判断权值，不判断是否连通

删边后可能图直接不连通了，根本生成不了 MST。这时候权值可能很小（因为边不够），但实际上是不合法的。

**解决方法**：同时判断 `edgeCnt != n - 1`（边数不够说明不连通）。

```cpp
// 错误：只判断权值
if (val > mst_val) { ... }

// 正确：还要判断是否连通
if (edgeCnt != n - 1 || val > mst_val) { ... }
```

### 坑 3：强制加边时忘记先合并端点

判断伪关键边时，"强制加入"不是只加权值，还要真的把两个端点合并到并查集里，否则后续 Kruskal 可能又选了这条边，或者选了其他能连通这两个点的边，结果就不对了。

**解决方法**：先 `join(u, v)` 合并端点，再加上权值。

### 坑 4：关键边和伪关键边的判断顺序

一定要**先判断是不是关键边**，如果是关键边就直接跳过伪关键边的判断。因为关键边一定能通过"强制加边"测试（它本来就在 MST 里），如果不跳过，关键边会被错误地同时归类到伪关键边里。

```cpp
if (是关键边) {
    critical.push_back(idx);
    continue; //  关键边不可能是伪关键边，直接跳过
}
// 再判断伪关键边
```

## 手动模拟示例

拿示例来走一遍，帮你理解：

```
n = 5, edges = [
  [0,1,1],  // 边 0
  [1,2,1],  // 边 1
  [2,3,2],  // 边 2
  [0,3,2],  // 边 3
  [0,4,3],  // 边 4
  [3,4,3],  // 边 5
  [1,4,6]   // 边 6
]
```

**标准 MST 权值**：选边 0、1、2、4，总权值 = 1 + 1 + 2 + 3 = 7

**判断边 0（0-1，权值1）**：
- 删边 0：剩下的边里没有其他权值为 1 的边能连通 0 和 1，MST 权值会变大 → **关键边** ✓

**判断边 2（2-3，权值2）**：
- 删边 2：可以选边 3（0-3，权值2）替代，MST 权值还是 7 → 不是关键边
- 强制加边 2：总权值还是 7 → **伪关键边** ✓

**判断边 6（1-4，权值6）**：
- 删边 6：MST 权值不变（本来就没选它）
- 强制加边 6：总权值变成 1+1+2+6 = 10 > 7 → 都不是 ✓

## 总结

> 怎么找 MST 里的关键边和伪关键边？
>
>
>
> 这道题可以用 **Kruskal + 并查集 + 暴力枚举** 的思路来做。
>
> 首先，先跑一遍标准的 Kruskal 算法，求出 MST 的总权值 `mst_val`。
>
> 然后，对每一条边做两次验证：
>
> 第一次是**删边验证**：把这条边从图中删掉，重新跑 Kruskal。如果删边后无法连通所有节点，或者 MST 的权值变大了，说明这条边是不可替代的，它就是**关键边**。
>
> 第二次是**强制加边验证**：如果不是关键边，就强制把这条边加入 MST——先把它的两个端点合并，并加上它的权值，然后继续跑 Kruskal。如果最终总权值仍然等于 `mst_val`，说明这条边可以出现在某个 MST 中，它就是**伪关键边**。
>
> 时间复杂度是 O(m² · α(n))，m 是边数。因为 m 最多 200，m² 也就 4 万，完全可以过。
>
> 这里有几个需要注意的点：一是排序后要记录边的原始索引，不然最后不知道返回哪个编号；二是删边后不仅要看权值，还要看能不能连通所有节点；三是关键边要先判断，判断完就跳过伪关键边的验证，不然会重复归类。
