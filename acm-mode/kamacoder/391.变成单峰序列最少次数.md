# [Minimum Operations To Single Peak](https://kamacoder.com/problempage.php?pid=1471)

---

> 数据范围：3 ≤ n ≤ 10^5，1 ≤ ai ≤ 10^7。时间限制 1s。
>
> 题型：贪心 / 动态规划（前后缀分解）。只能对元素做 **+1** 操作（次数不限），求把序列变成「严格先增后减、且峰顶不在两端」的单峰序列所需的最小总增量。
>
> 注意：总增量可能达 10^10 量级，变量必须用 64 位整数（long long）。

## 动态规划 / 前后缀分解 思路分析

题目要求将给定的序列通过做加法（且只能加，每次 +1，次数不限）变成一个严格的单峰序列，并使得总的加法操作次数最小。单峰序列的特点是存在一个峰顶位置，左侧严格单调递增，右侧严格单调递减。

为了使总操作次数（即增加量之和）最小，我们需要使得变化后的每个元素尽可能地小。

假设序列下标从 0 到 n-1，我们可以在 O(N) 时间内预处理出两个方向的数组：

**前缀 DP（变为递增）：**
定义 `L_val[i]` 为使前缀 `a[0...i]` 变为严格递增序列时，第 i 个位置的最小合法值；
定义 `L_cost[i]` 为相应的最小代价之和。

状态转移：
- `L_val[i] = max(a[i], L_val[i-1] + 1)`
- `L_cost[i] = L_cost[i-1] + (L_val[i] - a[i])`

**后缀 DP（变为递减）：**
定义 `R_val[i]` 为使后缀 `a[i...n-1]` 变为严格递减序列时（从左往右看是严格递减），第 i 个位置的最小合法值；
定义 `R_cost[i]` 为相应的最小代价之和。

状态转移：
- `R_val[i] = max(a[i], R_val[i+1] + 1)`
- `R_cost[i] = R_cost[i+1] + (R_val[i] - a[i])`

**寻找最优峰顶：**
枚举每一个可能的峰顶位置 k（1 ≤ k ≤ n-2）。为了满足单峰性质，位置 k 的值 `peak` 必须同时严格大于其左边修改后的值 `L_val[k-1]` 和右边修改后的值 `R_val[k+1]`，并且不能低于原本的值 `a[k]`。

即：`peak = max(a[k], max(L_val[k-1] + 1, R_val[k+1] + 1))`。

以 k 为峰顶的全局总代价为：`Total_cost = L_cost[k-1] + R_cost[k+1] + (peak - a[k])`。

遍历所有的 k，找出产生最小 `Total_cost` 的组合即可。

## 复杂度分析

- 时间复杂度：O(N)；
- 空间复杂度：O(N)。

## 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    // 优化输入输出
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    vector<long long> L_val(n), L_cost(n);
    L_val[0] = a[0];
    L_cost[0] = 0;
    for (int i = 1; i < n; i++) {
        L_val[i] = max(a[i], L_val[i-1] + 1);
        L_cost[i] = L_cost[i-1] + (L_val[i] - a[i]);
    }
    vector<long long> R_val(n), R_cost(n);
    R_val[n-1] = a[n-1];
    R_cost[n-1] = 0;
    for (int i = n - 2; i >= 0; i--) {
        R_val[i] = max(a[i], R_val[i+1] + 1);
        R_cost[i] = R_cost[i+1] + (R_val[i] - a[i]);
    }
    long long min_total = -1;
    for (int k = 1; k < n - 1; k++) {
        long long peak = max({a[k], L_val[k-1] + 1, R_val[k+1] + 1});
        long long total = L_cost[k-1] + R_cost[k+1] + (peak - a[k]);
        if (min_total == -1 || total < min_total) {
            min_total = total;
        }
    }
    cout << min_total << "\n";
    return 0;
}
```

## 关键细节 / 易错点

- **必须用 64 位整数（long long）**：最大代价约为 `n × (max_ai + n)` ≈ 10^5 × 10^7 = 10^12 量级，远超 int 上限（≈2×10^9），用 int 会溢出。
- **严格单调**：相邻差至少 1，所以用 `L_val[i-1] + 1` / `R_val[i+1] + 1` 强制严格递增 / 递减，不能漏掉 `+1`。
- **峰顶必须在内部**：`1 ≤ k ≤ n-2`（0-indexed），循环写成 `for (int k = 1; k < n - 1; k++)`；写成 `0..n-1` 会允许峰在端点，违反单峰定义。
- **左右段相互独立，只在峰顶汇合**：左段 [0, k-1] 与右段 [k+1, n-1] 的最小合法值互不依赖，各自贪心取最小即可；峰顶取「原值 / 左邻+1 / 右邻+1」三者最大，保证同时严格大于两侧。
- **只许加不许减**：所有修改值都以 `max(a[i], …)` 起步，绝不会把原数改小。

## 一句话总结

对每个内部峰顶 k，左段贪心成最小严格递增、右段贪心成最小严格递减，峰顶取 `max(原值, 左邻+1, 右邻+1)`；用前后缀数组 O(N) 预处理，枚举 k 取最小总增量，全程 long long 防溢出。
