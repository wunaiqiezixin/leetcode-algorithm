# [xiaoming visits park](https://kamacoder.com/problempage.php?pid=1155)

> 数据范围：1 <= N, M, Q <= 1000，边权 w ∈ [1, 10000]（**非负，且为无向图**）
> 题型：**多组任意点对最短路查询**。两种主流解法：
> 1. **Dijkstra 堆优化** —— 对每个查询以 `start` 为源点跑一次最短路，正权图首选，复杂度 O(Q·(N+M)logN)，N=1000 稳过；
> 2. **Floyd-Warshall** —— 一次性全源预处理 O(N³)，之后每个查询 O(1) 查表，思路最简洁，但 N 较大时易超时。
> 与 [参加科学大会](./acm-mode/kamacoder/0047.参加科学大会.md) 的区别："参加科学大会" 是固定 1→N 单次查询；本题是 **Q 组任意 start→end 查询**。

## 题目分析

公园有 N 个景点、M 条**双向**道路，每条路长度 `w`（已知正数）。
小明有 Q 个观景计划，每个计划给定起点 `start` 和终点 `end`，求它们之间的最短路径长度。

输出：对每个查询输出一行 —— 最短路径长度；**若两点不连通则输出 `-1`**。

| 情况 | 输出 |
|------|------|
| start 到 end 有路 | 整数 `dist[end]`（最短路长度） |
| start 到 end 不连通 | `-1` |

## 为什么用 Dijkstra

- **边权为正（w ≥ 1）** → 满足 Dijkstra 适用前提，直接上堆优化 Dijkstra，不必用 Bellman-Ford。
- **无向图** → 建图时每条边要加两次（双向）。
- **Q 组查询** → 朴素想法是为每个查询以 `start` 为源点跑一次 Dijkstra：
  复杂度 Q × O((N+M) log N) = 1000 × (2000) × log(1000) ≈ 2e7，完全能过。

> **Floyd 行不行？** Floyd 是 O(N³)，N=1000 时约 1e9 次运算，在严格时限下**有 TLE 风险**，
> 所以**实际提交优先用 Dijkstra**。但 Floyd 代码更短、一次预处理后查询 O(1)，且本题边权非负、图稳定，
> **当 N 较小（如 N≤400）或想用「全源最短路」思路解题时，Floyd 完全成立** —— 下方「Floyd-Warshall 解法」给出完整代码。
> 一句话：**N 大用 Dijkstra，N 小 / 求 all-pairs 用 Floyd**。

> 与 [参加科学大会](./acm-mode/kamacoder/0047.参加科学大会.md) 同属 Dijkstra 单源最短路，只是本题是多组查询、且图为无向（双向边）。

## 核心思想：多查询 → 每次以 start 为源点跑 Dijkstra

每读入一个查询 `(start, end)`：
1. 以 `start` 为源点，初始化 `dist[start]=0`，其余 INF。
2. 跑**堆优化 Dijkstra**：小根堆按距离升序取点，松弛邻居。
3. 弹出终点 `end` 时（第一次）即可提前退出，其距离就是最短路。
4. 输出 `dist[end]`，若为 INF 则输出 `-1`。

每个查询独立跑一次，互不干扰（dist 数组每次重建）。

## 关键细节

1. **无向图加双向边**：`adj[u].push_back({v,w}); adj[v].push_back({u,w});` 漏掉反向边会 WA。
2. **正权 → Dijkstra 成立**：若以后边权出现负，必须换 Bellman-Ford 。
3. **懒删除**：`if (d > dist[u]) continue;` 跳过堆中过期记录，保证正确。
4. **提前退出**：`if (u == end) break;` 正权图下第一次弹出 end 即最短路，可省后续计算。
5. **不连通输出 -1**：`dist[end] == INF` 时输出 -1，不要假设一定能到。
6. **dist 类型**：w≤10000、N≤1000，最短路最大约 1e7，`int` 够用；为与前面几题风格统一用 `long long + 1e18` 更稳妥。

## 复杂度

- 时间：每个查询一次 Dijkstra，O((N+M) log N)；Q 个查询 → **O(Q·(N+M) log N)** ≈ 2e7，稳过。
- 空间：邻接表 O(N+M)，dist 数组 O(N)，堆最坏 O(M) → **O(N+M)**。

## 易错点

1. **无向边只加一条**：忘记 `adj[v].push_back({u,w})`，导致图变单向，路径算错。
2. **忘记重置 dist**：多组查询必须把 dist 重置（每次循环内新建），否则沿用上次结果。
3. **漏懒删除**：`if (d > dist[u]) continue;` 不写，可能用过期大距离松弛邻居，得到错误答案。
4. **不连通没判 -1**：直接输出 `dist[end]` 会输出 INF（极大数），应判 `== INF` 输出 -1。
5. **Q 组输出顺序**：每个查询一行，顺序与输入查询顺序对应，别漏输出。

## 完整代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 无向图：邻接表，每条双向道路加两条有向边
    vector<vector<pair<int, int>>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});          // 无向：反向也加
    }

    int q;
    cin >> q;

    const long long INF = 1e18;            // 足够大，且 INF + w 不会溢出

    // 每个查询：以 start 为源点跑一次堆优化 Dijkstra
    while (q--) {
        int start, end;
        cin >> start >> end;

        vector<long long> dist(n + 1, INF);
        dist[start] = 0;

        // 小根堆（优先队列）：(距离, 节点)，距离小的在堆顶
        priority_queue<pair<long long, int>,
                       vector<pair<long long, int>>,
                       greater<pair<long long, int>>> pq;
        pq.push({0, start});

        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();

            if (d > dist[u]) continue;     // 懒删除：跳过堆中过期记录
            if (u == end) break;           // 提前退出：正权图第一次弹到终点即最短路

            for (auto& [v, w] : adj[u]) {  // 松弛所有邻居
                if (dist[v] > d + w) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
            }
        }

        if (dist[end] == INF) cout << -1 << '\n';   // 不连通
        else cout << dist[end] << '\n';             // 最短路长度
    }

    return 0;
}
```

## 另一种解法：Floyd-Warshall（全源最短路，预处理一次、查询 O(1)）

### 思路对比

| 维度 | Dijkstra（每查询跑一次） | Floyd-Warshall（一次预处理） |
|------|------------------------|----------------------------|
| 核心 | 单源最短路，以 `start` 为源 | 全源最短路，一次性算出任意 `i→j` |
| 预处理 | 无（每次查询现算） | O(N³) 三重循环 |
| 单查询 | O((N+M) log N) | O(1) 直接查表 |
| Q 组总复杂度 | O(Q·(N+M) log N) ≈ 2e7 | O(N³ + Q)，N 大时主导项 1e9 |
| N=1000 时限风险 | 低，稳过 | **高，易 TLE** |
| 代码量 | 较长（堆+邻接表） | 极短（三重循环即可） |

Floyd 的本质：**用每个点 `k` 作为「中转站」，尝试用它缩短所有点对 `i→j` 的距离**。
三层循环顺序必须固定为 `k → i → j`（k 最外层），因为 `k` 必须在 `i,j` 更新前就「全部生效」。

### 核心思想

1. `dist[i][j]` 初始化：自己到自己是 0；每条无向边 `u-v,w` 使 `dist[u][v]=dist[v][u]=min(原值, w)`（可能重边，取最小）。
2. 三重循环：
   ```
   for k: for i: for j:
       dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
   ```
3. 预处理完后，每个查询直接 `dist[start][end]`：为 INF 则 `-1`，否则输出该值。

### 关键细节

1. **INF 防溢出**：松弛前加 `dist[i][k] != INF && dist[k][j] != INF` 判断，避免 `INF + INF` / `INF + w` 溢出污染。
2. **k 必须在最外层**：`k→i→j` 顺序是 Floyd 正确性的前提，写反会算错（本质是 DP 的阶段顺序）。
3. **无向图对称赋值**：`dist[u][v] = dist[v][u]`，且取 `min` 处理重边。
4. **不连通输出 -1**：`dist[start][end] == INF` 时输出 -1。
5. **空间**：邻接矩阵 O(N²)，N=1000 时为 1e6 个 `long long` ≈ 8MB，可接受。
6. **时限风险**：N=1000 时三重循环约 1e9 次，C++ 极限下约 1~2s，**多数 OJ 会 TLE**；这是它不如 Dijkstra 的根本原因。

### 完整代码（C++ · Floyd-Warshall）

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    const long long INF = 1e18;
    // 邻接矩阵：dist[i][j] 初始为 i 到 j 的直接边权
    vector<vector<long long>> dist(n + 1, vector<long long>(n + 1, INF));
    for (int i = 1; i <= n; ++i) dist[i][i] = 0;

    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        // 无向图对称赋值；可能重边，取最小
        if (w < dist[u][v]) {
            dist[u][v] = w;
            dist[v][u] = w;
        }
    }

    // Floyd-Warshall：k 必须在最外层，作为中转点更新所有点对
    for (int k = 1; k <= n; ++k)
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= n; ++j)
                // 先判可达，避免 INF+w 溢出
                if (dist[i][k] != INF && dist[k][j] != INF &&
                    dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];

    int q;
    cin >> q;
    while (q--) {
        int start, end;
        cin >> start >> end;
        if (dist[start][end] == INF) cout << -1 << '\n';  // 不连通
        else cout << dist[start][end] << '\n';            // 直接查表
    }

    return 0;
}
```

### 示例推演（用题目示例）

输入：
```
7 3
2 3 4
3 6 6
4 7 8
2
2 3
3 4
```
- 初始矩阵：dist[2][3]=dist[3][2]=4，dist[3][6]=dist[6][3]=6，dist[4][7]=dist[7][4]=8，其余 INF（对角 0）。
- Floyd 跑完：2→3 仍 4；3 与 4 之间无任何连通路径（3 只连 2、6；4 只连 7），dist[3][4]=INF。
- 查询 `2 3` → 4；查询 `3 4` → -1。与示例输出一致。

## 一句话总结

无向正权图 + Q 组任意点对查询，两种解法：

- **Dijkstra（推荐提交）**：对每个查询以 `start` 为源点跑一次堆优化 Dijkstra，无向图**双向加边**，输出 `dist[end]`（不连通 `-1`），复杂度 O(Q·(N+M)logN)，N=1000 稳过。核心仍是**懒删除** + **提前退出**，和 [参加科学大会](./acm-mode/kamacoder/0047.参加科学大会.md) 同宗，只是从单查询变成了多查询循环。
- **Floyd-Warshall（思路最简洁）**：一次性三重循环 `k→i→j` 算出全源最短路，之后查询 O(1) 查表；代码极短，但 O(N³) 在 N=1000 时**易 TLE**，适合 N 较小或追求 all-pairs 的场景。

**取舍：N 大用 Dijkstra，N 小 / 求全源用 Floyd；都别忘了双向边和不连通的 `-1`。**
