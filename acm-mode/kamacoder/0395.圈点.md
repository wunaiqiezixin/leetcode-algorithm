# [Circle Points](https://kamacoder.com/problempage.php?pid=1475)

> 数据范围：`2 <= n <= 10^5`，坐标 `xi, yi ∈ [-10^5, 10^5]`；圆心必须落在 **x 轴或 y 轴**上；半径保留 6 位小数
>
> 题型：**二分答案（半径）+ 扫描线（求区间最大重叠）**。把"圆覆盖点"在固定轴上转化为"一维区间重叠"，半径越大可覆盖点数单调不减 → 二分；对每个候选半径用扫描线求最多有多少点能被同一圆心覆盖。

## 题目分析

要在坐标平面上画一个圆，**圆心必须在坐标轴上**（x 轴 `(a,0)` 或 y 轴 `(0,a)`），求能覆盖**不少于一半（至少 `⌈n/2⌉` 个）点**的最小半径 `r`（保留 6 位小数）。

题目表述为"不少于 `[n/2]` 个点"，这里的覆盖要求实际是**至少一半、向上取整**，即 `need = (n + 1) / 2`（C++ 整数除法天然向下取整，`(n+1)/2` 恰好等于 `⌈n/2⌉`）。偶数 `n` 时 `(n+1)/2 == n/2` 二者一致；**奇数 `n` 时向上取整比向下取整多覆盖 1 个点，是本题判题关键，务必用 `(n+1)/2`**。

### 固定圆心在 x 轴上的几何转化

设圆心 `(a, 0)`，半径 `r`。点 `P(xi, yi)` 被覆盖 ⇔ 欧氏距离 ≤ r：

```
(xi - a)^2 + yi^2 <= r^2
⇔ (xi - a)^2 <= r^2 - yi^2
```

- 若 `|yi| > r`：垂直方向距离已经超了，**任何 a 都覆盖不到**该点（剪枝）。
- 若 `|yi| <= r`：可覆盖，且 `a` 必须满足 `a ∈ [xi - d, xi + d]`，其中 `d = sqrt(r^2 - yi^2)`。

**于是每个可被覆盖的点，在"圆心横坐标 a"这条一维轴上对应一个闭区间 `[xi - d, xi + d]`**。问题变成：是否存在某个 `a`，使得**至少 `need` 个区间重叠**？ —— 经典扫描线(Sweep Line)。

y 轴完全对称：把 `x, y` 互换，圆心横坐标 `a` 换成纵坐标即可。两个轴各自算最小可行 `r`，取较小者。

## 为什么用二分 + 扫描线（算法选型对比）

| 做法 | 思路 | 复杂度 | 评价 |
|---|---|---|---|
| 枚举圆心候选（几何） | 最优圆必过 ≥2 个点，枚举点对解 `a` | O(n³) | n=1e5 必超时，仅适合小数据/对拍 |
| 直接枚举半径 + 排序扫描 | 半径单调 ⇒ 二分；每轮扫描线判重叠 | O(n log n · log(1/ε)) | 本题正解，OJ 可过 |
| 暴力枚举所有圆心 | 不可行（圆心连续） | — | × |

- 关键单调性：**半径 r 越大，每个点的可行区间 `[xi-d, xi+d]` 越长（d 随 r 增大），能重叠的点只会不减**。所以"能否覆盖 need 个点"是关于 r 的单调性质 → 二分答案。
- 二分值域 `r ∈ [0, 3e5]`（理论上覆盖全部点只需 ≤ sqrt{2}·1e5 ≈ 1.4e5，留足余量到 3e5），迭代 65 次即可把误差压到 ~1e-15，远小于 6 位小数要求。

## 核心思想

1. **二分半径 `r`**：`mid = (lo+hi)/2`。
2. **可行性检查 `feasible(r)`**，分别对 x 轴、y 轴 **(Sweep Line)** ：
   - 遍历点，跳过 `|perp| > r` 的点（垂直距离超限）。
   - 其余点生成区间端点事件 `(L, -1)`（进入，覆盖 +1）、`(R, +1)`（离开，覆盖 -1）。
   - 按 `(位置, 类型)` 排序（同位置时 `-1` 在前 ⇒ 闭区间端点正确计入）。
   - 扫描累加当前重叠数 `cur`，一旦 `cur >= need` 即返回 `true`。
   - 两轴任一可行则 `r` 可行。
3. 可行 → `hi = mid`（尝试更小），不可行 → `lo = mid`。最终 `hi` 即最小半径。

## 关键细节

1. **闭区间端点顺序**：点落在 `a = L` 或 `a = R` 时距离恰为 `r`，算覆盖。用 `(位置, 类型)` 排序，类型 `-1`（起点）排在 `+1`（终点）前，保证在同一位置上"先加后进"，闭区间不漏算。若写反（终点先处理）会把恰在边界的点少算，导致误判不可行。
2. **垂直距离剪枝**：`|perp| > r` 的点本轮直接跳过，既是正确的几何约束，也避免 `r^2 - perp^2 < 0` 开方出 NaN（`sqrt(max(0.0, ...))` 兜底）。
3. **两个轴都要算**：圆心可以在 x 轴**或** y 轴，取两者可行半径的较小值，别只算一个轴。
4. **`need` 的取值（判题关键）**：本题覆盖要求是**至少一半、向上取整** `need = (n + 1) / 2`，**不是**向下取整 `n/2`。偶数 `n` 两者相等，奇数 `n` 会差 1 个，直接决定 WA/AC。
5. **输出精度**：`fixed << setprecision(6)`，二分迭代 65 次足够。

## 复杂度

- 时间：二分 ~65 轮 × 每轮 2 轴 × `O(n log n)`（排序 2n 个端点）≈ `O(n log n · 65)`，`n=1e5` 稳过 1s。
- 空间：`O(n)` 存点与事件。

## 易错点

1. **区间开闭写反**：本题圆覆盖是"距离 ≤ r"，区间闭；扫描线同坐标必须"起点先于终点"，否则边界点漏算。
2. **只算一个轴**：忘记 x 轴、y 轴取 min。
3. **`need` 取整方向（最容易错）**：本题必须 `need = (n + 1) / 2`（向上取整 / 至少一半）。写成 `n / 2`（向下取整）在奇数 `n` 时会少算 1 个，正好 WA。
4. **二分边界/精度**：`hi` 开太小（< 实际所需）会判不可行；迭代次数太少（< ~50）精度不够。本题 `hi=3e5`、65 次足够。
5. **垂直距离漏剪枝**：不跳过 `|perp|>r` 会让 `sqrt` 参数变负（NaN），区间错乱。

## 完整代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>
#include <iomanip>
using namespace std;

// 圆心在某坐标轴上、半径 r 时，能否覆盖至少 need 个点
// axis == 0: 圆心 (a, 0)；axis == 1: 圆心 (0, a)
bool feasible(const vector<pair<int, int>>& pts, double r, int need, int axis) {
    vector<pair<double, int>> ev;   // (位置, 类型)：-1=进入(+1覆盖)  +1=离开(-1覆盖)
    int coverable = 0;
    for (auto [x, y] : pts) {
        double perp, coord;
        if (axis == 0) { perp = abs(y); coord = x; }   // x 轴：垂直距离是 |y|
        else           { perp = abs(x); coord = y; }   // y 轴：垂直距离是 |x|
        if (perp > r + 1e-12) continue;                // 垂直距离已超 r，必覆盖不到
        double d = sqrt(max(0.0, r * r - perp * perp));
        ev.emplace_back(coord - d, -1);                // 进入区间
        ev.emplace_back(coord + d,  1);                // 离开区间
        ++coverable;
    }
    if (coverable < need) return false;
    // 同坐标：类型 -1(起点) 排在 +1(终点) 前 => 闭区间端点正确计入
    sort(ev.begin(), ev.end());
    int cur = 0;
    for (auto [pos, typ] : ev) {
        cur -= typ;                                    // 起点(-1) => +1；终点(+1) => -1
        if (cur >= need) return true;
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<pair<int, int>> pts(n);
    for (int i = 0; i < n; ++i) cin >> pts[i].first >> pts[i].second;

    // 覆盖要求：至少一半（向上取整）=> (n + 1) / 2
    int need = (n + 1) / 2;

    double lo = 0.0, hi = 3e5;
    for (int it = 0; it < 65; ++it) {                  // 65 次：误差 < 1e-15
        double mid = (lo + hi) / 2.0;
        if (feasible(pts, mid, need, 0) || feasible(pts, mid, need, 1))
            hi = mid;                                  // 可行，尝试更小的半径
        else
            lo = mid;
    }
    cout << fixed << setprecision(6) << hi << '\n';
    return 0;
}
```

## 一句话总结

圆心限在坐标轴上 ⇒ 固定轴后每个点变成"圆心坐标"一维轴上的闭区间 `[coord - sqrt{r²-perp²}, coord + sqrt{r²-perp²}]`；半径越大区间越长、可覆盖点数单调不减 ⇒ **二分半径 + 扫描线求最大区间重叠**，`cur >= need` 即可行，两轴取 min；注意闭区间端点（同坐标起点先于终点）、垂直距离剪枝、以及 `need = (n + 1) / 2`（向上取整，不是 `n/2`）。
