# [oppo chess board](https://kamacoder.com/problempage.php?pid=1457)

> 数据范围：1 ≤ n ≤ 10⁵，0 ≤ m ≤ 10⁵，1 ≤ c ≤ 30，1 ≤ kᵢ ≤ 10⁹，1 ≤ d ≤ 10⁴。
>
> 题型：**有向图多源最短路 + 次小值维护**（计数型，按颜色分组跑 Dijkstra）。
>
> 关键性质：安全 = 不存在"另一个同色棋子能在有向边 kᵢ 距离内走到我"。只需对每个颜色，求出每个棋子**被其他同色棋子攻击的最短距离（次小最短路，且起点不同）**，再与 kᵢ 比较。

## 题目分析

每个棋子有颜色 `cᵢ` 和攻击距离 `kᵢ`。棋子 B 会被棋子 A 攻击 ⟺ `color[A]==color[B]` 且 **A→B 的有向最短路 ≤ k_{color}**。

一个棋子不安全 ⟺ 存在**另一个**同色棋子能在攻击距离内到达它。我们要数"安全棋子"总数。

**朴素想法**：对每个棋子当目标，跑单源最短路，看有没有同色源点距离 ≤ kᵢ。复杂度 n × O((n+m)log n) ≥ 10¹⁰，必超时。
**优化**：同一颜色的棋子"攻击者"是同一群。对一个颜色，把所有同色棋子**同时作为源点**丢进一个 Dijkstra（多源最短路），每个节点记录"`从哪个源来`的最短距离"。那么对某个目标棋子 v，能攻击它的最近同色源就是"**起点不同于 v 的最小距离**"——也就是 `second[v]`（次小最短路，且要求两条最短路来自**不同源点**）。

## 为什么用多源 Dijkstra + 次小（算法选型）

| 思路 | 做法 | 复杂度 | 评价 |
|------|------|--------|------|
| 每点跑单源 Dijkstra | n 次最短路 | O(n·(n+m)log n) | n=10⁵ 直接炸 |
| Floyd 全源最短路 | 三重循环 | O(n³) | n=10⁵ 必超时 |
| **按颜色分组多源 Dijkstra + 次小值** | 每个颜色一次多源 Dijkstra，记录"不同源的次小距离" | O(c·(n+m)log n) | c≤30，约 3×10⁷，稳过 |

因为 c 很小（≤30），按颜色把图切成最多 30 次多源 Dijkstra。每次处理一个颜色：把该颜色所有棋子作为源点（距离 0）入堆，跑一遍 Dijkstra，对每个节点维护 `best`（最近同色源距离）和 `second`（次近**不同源**距离）。最后对同色棋子 v，若 `second[v] ≤ kᵢ` 则它不安全。

## 核心思想：多源 Dijkstra 如何维护"不同源的次小距离"

- `best[u]`：从某同色源到 u 的**最短**距离；`bsrc[u]`：这条最短路来自哪个**源点编号**。
- `second[u]`：从**另一个不同源点**到 u 的**最短**距离（即"次小，且起点 ≠ best 的起点"）。这才是"别的同色棋子能打到我"的最近距离。
- 松弛边 (u,w,wt)，新距离 `nd = d + wt`，来自源 s：
  - 若 `nd < best[w]`：原本的 `best[w]`（若来自不同源）降级为 `second[w]` 的候选；再把 `best[w]=nd`、`bsrc[w]=s`。
  - 否则若 `nd < second[w]` 且 `s != bsrc[w]`（确保不是同一源重复）：更新 `second[w]=nd`。
- **出堆剪枝**：`if (d > second[u]) continue;` —— 当 d 已经比 `second[u]` 还大时，它既当不了 best 也当不了 second（两个位置都被更小且不同源的值占了），是真正过期，可丢。
> 注意：**不能**写成 `if (d > best[u]) continue;`。那样会丢掉"用次小源继续松弛"的机会——次小源的边可能给别的节点提供新的 `second`，漏掉它会导致本该不安全的棋子被判安全。

- 目标棋子 v 若 `second[v] ≤ kᵢ`，说明存在另一个同色棋子能在攻击距离内走到它 → **不安全**。
- 颜色只有 1 个棋子（或 0 个）：没有任何"另一个同色棋子"，天然安全，跳过该颜色即可。

## 关键细节

- **答案用 `long long`**：`kᵢ` 可达 10⁹，距离累加 `m·d` 最大 10⁹，且 INF 取 `1e18`。`d ≤ 10⁴` 是整数，但匹配类型用 `long long` 防溢出，尤其松弛 `nd = d + wt` 与 INF 比较时。
- **每个颜色独立跑**：`best/second/bsrc` 每色重新初始化（vector 每色重声明即可，天然清空）。
- **多源入堆**：同色所有棋子初始 `best=0, dist=0, src=自己` 一起 push，等价于超级源连 0 边，但不用真的建超级源。
- **次小必须"不同源"**：同一源点到自己的距离 0 不能算"别人攻击我"，`second` 的定义天然排除了（因为要求 `s != bsrc[w]`）。
- **大数组走堆**：`best/second/bsrc` 用 `vector<long long>`（或全局数组），不裸放函数内（防爆栈）。这里 n=10⁵，vector 在堆上，没问题。

## 复杂度

- 每个颜色跑一次多源 Dijkstra，单次 O((n+m) log n)（边/点规模仍是全图，因为同色源散布全图）。
- 共 c 个颜色：O(c·(n+m) log n)。c≤30，n,m≤10⁵ → 约 30 × 2×10⁵ × 17 ≈ 10⁸ 量级，C++ 1s 稳过（实际常数很小）。
- 空间 O(n+m)。

## 易错点

1. **把 n 次单源 Dijkstra 当做法** → 超时（10¹⁰）。必须按颜色分组多源。
2. **用"最短路"而非"次小不同源最短路"判安全** → 自己到自己是 0，会误判每个棋子都被"自己"攻击而不安全。必须看的是 `second`（排除自身源）。
3. **次小维护没要求"不同源"** → 同一条路径被重复算，sub 值失真。
4. **出堆剪枝写成 `d > best[u]`** → 丢掉次小源的松弛，漏判不安全（关键 bug）。应写 `d > second[u]`。
5. **答案 `int` 溢出**：距离和 kᵢ 用 `long long`。
6. **漏掉"颜色只有 1 个棋子"的边界**：该颜色所有棋子都安全，但代码若对 `second` 取默认值 INF 比较，不影响（INF > kᵢ），所以天然正确；只是别画蛇添足去判 `second[v]` 是否存在——直接 `if (second[v] <= K) unsafe` 即可，INF 永远不 ≤ K。

## 完整代码（C++，兼容 C++11）

> C++11 兼容要点：去掉 `tuple`、结构化绑定 `auto [a,b,c]`、`emplace(0,v,v)`、`greater<>` 空模板；小顶堆改用 `pair<ll, pair<int,int>>`，`greater<P>` 显式写模板参数，循环用下标/迭代器。

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

typedef long long ll;
const ll INF = 1e18;

// 多源 Dijkstra：求每个节点"来自不同源的次小最短距离"
// second[v] = 其他同色源到 v 的最短距离（v 自己是源之一时排除自身）
void multiSourceSecond(const vector<vector<pair<int, int> > >& adj,
                       const vector<int>& srcs,
                       vector<ll>& second) {
    int n = (int)adj.size() - 1;
    vector<ll> best(n + 1, INF);
    vector<int> bsrc(n + 1, -1);
    second.assign(n + 1, INF);

    // 小顶堆：(dist, (node, source_id))
    typedef pair<ll, pair<int, int> > P;
    priority_queue<P, vector<P>, greater<P> > pq;
    for (size_t i = 0; i < srcs.size(); ++i) {
        int v = srcs[i];
        best[v] = 0;
        bsrc[v] = v;                       // 以自身编号标识源（同色每个棋子编号唯一）
        pq.push(P(0, make_pair(v, v)));
    }

    while (!pq.empty()) {
        P cur = pq.top(); pq.pop();
        ll d = cur.first;
        int u = cur.second.first;
        int s = cur.second.second;
        if (d > second[u]) continue;      // 真正过期：连次小都当不了
        for (size_t i = 0; i < adj[u].size(); ++i) {
            int w  = adj[u][i].first;
            int wt = adj[u][i].second;
            ll nd = d + wt;
            if (nd < best[w]) {
                // 旧 best 来自不同源 => 降级为 second 候选
                if (bsrc[w] != s && best[w] < second[w]) second[w] = best[w];
                best[w] = nd;
                bsrc[w] = s;
                pq.push(P(nd, make_pair(w, s)));
            } else if (nd < second[w] && s != bsrc[w]) {
                // 来自不同源、且比当前 second 小 => 更新（注意：必须 != bsrc[w]）
                second[w] = nd;
                pq.push(P(nd, make_pair(w, s)));
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL);

    int n, m, c;
    if (!(cin >> n >> m >> c)) return 0;        // 注意：!(cin >> ...)

    vector<int> color(n + 1);
    for (int i = 1; i <= n; ++i) cin >> color[i];

    vector<ll> K(c + 1);
    for (int i = 1; i <= c; ++i) cin >> K[i];

    vector<vector<pair<int, int> > > adj(n + 1);  // (to, weight)
    for (int i = 0; i < m; ++i) {
        int u, v, d;
        cin >> u >> v >> d;
        adj[u].push_back(make_pair(v, d));         // 有向边，只加一次
    }

    // 按颜色分组
    vector<vector<int> > byColor(c + 1);
    for (int i = 1; i <= n; ++i) byColor[color[i]].push_back(i);

    vector<bool> safe(n + 1, true);
    vector<ll> second;                            // 复用，每次重新 assign

    for (int col = 1; col <= c; ++col) {
        const vector<int>& srcs = byColor[col];
        if (srcs.size() <= 1) continue;           // 同色棋子不足 2 个 => 都安全
        ll kVal = K[col];
        multiSourceSecond(adj, srcs, second);
        for (size_t i = 0; i < srcs.size(); ++i) {
            int v = srcs[i];
            if (second[v] <= kVal) safe[v] = false;   // 有别处同色棋子能打到 => 不安全
        }
    }

    int ans = 0;
    for (int i = 1; i <= n; ++i) if (safe[i]) ++ans;
    cout << ans << '\n';
    return 0;
}
```

## 一句话总结

安全 = 不存在另一个同色棋子在攻击距离内有向可达。按颜色分组，每组把所有同色棋子当源点跑一次**多源 Dijkstra**，对每个节点维护"**来自不同源的次小最短距离** second"——次小（不是最小，最小是自身）才是"别人能打到我"的最近距离；若 `second[v] ≤ kᵢ` 则不安全。复杂度 **O(c·(n+m)log n)**，c≤30 稳过。剪枝务必用 `d > second[u]`（不是 `best[u]`），否则漏判不安全。
