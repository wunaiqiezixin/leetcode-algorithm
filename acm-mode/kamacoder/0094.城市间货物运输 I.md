# [intercity cargo transport I](https://kamacoder.com/problempage.php?pid=1152)

> 数据范围：1 <= n <= 1000，1 <= m <= 10000，边权 v ∈ [-100, 100]；保证无负权回路

## 题目分析

n 个城市、m 条**单向**道路，每条路有一个权值 `v = 运输成本 - 政府补贴`（可正可负）。
- v > 0：扣除补贴后仍需付钱；
- v < 0：补贴超过成本，运输反而**盈利**。

求从城市 1 到城市 n 的**最小综合运输成本**（即最短路径权值和，可为负 = 盈利）。
若 1 无法到达 n，输出字符串 `"unconnected"`。

题目明确保证：**道路网络中不存在任何负权回路**。这意味着最短路径一定存在且有限（只要可达），可以用 Bellman-Ford / SPFA 求解。

## 为什么不能用 Dijkstra

Dijkstra 的正确性依赖**非负权**——它假设“一旦取出某个点，它的最短距离就永久确定”。
但本题边权 `v ∈ [-100, 100]` 含负值：一条更短的路径可能经过“先绕远路到负权边”再回来，
Dijkstra 的贪心会过早把节点“钉死”，从而**给出错误答案**。

> 一句话：有负权 → 必须换 Bellman-Ford 或 SPFA。

## 算法选择

| 算法 | 负权 | 负权回路 | 本题（n≤1000, m≤10000） |
|------|------|---------|------------------------|
| Dijkstra（堆优化） | 不支持 | — | 直接淘汰 |
| **Bellman-Ford** | 支持 | 可检测 | **O(n·m)=1e7，稳** |
| SPFA（队列优化 Bellman-Ford） | 支持 | 可检测 | 平均更快，但最坏仍 O(n·m) |

本题数据量不大，`n·m = 1e7`，朴素的 **Bellman-Ford** 完全够用且最好写、最不容易错。
下方代码用 Bellman-Ford，并加“无更新则提前退出”的优化。

## 核心思想：松弛 n-1 轮

Bellman-Ford 基于最短路的**三角不等式**：对任意边 `u->v`，
`dist[v] = min(dist[v], dist[u] + w)`。

- 一条最短路径最多经过 `n-1` 条边（不含回路，因为无负权回路）。
- 所以**最多松弛 n-1 轮**，每轮遍历所有 m 条边，就能把 1 到所有可达点的最短距离“推”到位。
- 某轮若没有任何一条边能再松弛，说明已收敛，可提前结束。

## 关键细节

1. **INF 取值与溢出防护**：用 `long long` + `INF = 1e18`。只在 `dist[u] != INF` 时才松弛
   （即 `dist[u] + w < dist[v]`），避免 `INF + 负数` 这种无意义甚至溢出的运算。
2. **不可达判据**：n-1 轮后若 `dist[n] == INF`，说明 1 到 n 没有路径 → 输出 `"unconnected"`。
3. **负权回路**：题目保证不存在，因此 n-1 轮后 `dist[n]` 就是答案（不会无限下降）。
   若题目不保证，需再做第 n 轮检测：仍有边可松弛则说明存在可达负环（本题不需要）。
4. **输出可为负**：盈利情况直接输出负数即可，不要取绝对值。

## 复杂度

- 时间：最多 n-1 轮 × m 条边 = **O(n·m)**，本题最坏 `1000 × 10000 = 1e7`，轻松。
- 空间：边表 O(m)、dist 数组 O(n) → **O(n + m)**。

## 易错点

1. **别用 Dijkstra**：看到“最短路”就条件反射用堆，本题有负权会 WA。
2. **从 INF 出发的边不要松弛**：务必加 `dist[u] != INF` 判断，否则 `INF + w` 可能溢出或污染结果。
3. **输出是 `"unconnected"` 不是 `-1`**：字符串原样输出，注意大小写。
4. **用 `long long`**：虽然数值不大，但多个负权累加、且要避免 INF 运算问题，long long 最稳。
5. **边权范围含负**：建边时 `w` 用 `int` 即可，但累加进 `dist` 时用 `long long`。

## 完整代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 边表存图：Bellman-Ford 需要按“边”遍历，存三个数组最直观
    vector<int> u(m), v(m), w(m);
    for (int i = 0; i < m; ++i) {
        cin >> u[i] >> v[i] >> w[i];   // 单向边 s->t，权值 v
    }

    const long long INF = 1e18;        // 足够大，且 INF + w 不会溢出
    vector<long long> dist(n + 1, INF);
    dist[1] = 0;                       // 起点到自身距离为 0

    // Bellman-Ford：最多 n-1 轮，每轮松弛所有边
    for (int i = 1; i < n; ++i) {
        bool updated = false;          // 本轮是否发生过松弛
        for (int j = 0; j < m; ++j) {
            // 只从“已可达”的点出发松弛；跳过 INF 避免 INF+w 溢出/误更新
            if (dist[u[j]] != INF && dist[u[j]] + w[j] < dist[v[j]]) {
                dist[v[j]] = dist[u[j]] + w[j];
                updated = true;
            }
        }
        if (!updated) break;           // 已收敛，提前结束（无负环时安全）
    }

    // 判可达：dist[n] 仍为 INF 表示 1 到 n 无路径
    if (dist[n] == INF) cout << "unconnected\n";
    else cout << dist[n] << '\n';      // 可为负数（盈利）

    return 0;
}
```

## 一句话总结

边权含负 → **Dijkstra 退役**，上 **Bellman-Ford**：存边表、`dist` 用 `long long` 初值 `1e18`、
每轮对所有边做 `dist[u]!=INF` 条件下的松弛，最多 n-1 轮（可提前退出）；
最后 `dist[n]==INF` 输出 `"unconnected"`，否则输出 `dist[n]`（可能为负 = 盈利）。
