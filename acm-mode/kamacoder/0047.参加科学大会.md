## 题目分析

小明要从 **1 号车站** 出发，到达 **N 号车站**，途中的公路都是 **单向** 的，每条路有对应的通行时间 `V`。
求：**1 -> N 的最小总通行时间**；如果根本到不了，输出 `-1`。

抽象成图论语言：

- 车站 = 节点（编号 1 ~ N）
- 单向公路 = **有向边** `u -> v`，边权 `w = V`（时间）
- 目标 = 求起点 `1` 到终点 `N` 的**最短路径长度**

这就是经典的 **单源最短路径（Single-Source Shortest Path）** 问题。

---

## 为什么选 Dijkstra？

| 算法 | 能否处理负权 | 时间复杂度 | 适用场景 |
|------|------------|-----------|---------|
| BFS | 仅边权全为 1 | O(N+M) | 无权/等权图 |
| **Dijkstra（堆优化）** | **不能**（权必须非负） | **O((N+M) log N)** | **本题：时间一定非负** |
| Bellman-Ford | 能 | O(N·M) | 含负权、判负环 |
| SPFA | 能（平均快） | 期望 O(N+M)，最坏 O(N·M) | 含负权，但易被卡 |

本题中“通行时间”显然是非负的，因此 **Dijkstra 是最优解**：既正确又高效，且不会被特殊数据卡成 O(N·M)。

> 如果题目出现负权边，请改用 SPFA / Bellman-Ford；本题不需要。

---

## 核心思想：贪心 + 松弛

Dijkstra 的本质是 **带“已确定”标记的贪心**：

1. 维护每个点 `u` 的“当前已知最短路” `dist[u]`，初始 `dist[1]=0`，其余为无穷大。
2. 每次从**所有未确定**的点里，挑一个 `dist` 最小的点 `u`，把它**永久确定**（它不可能再被更短路更新——这就是贪心正确性的来源，依赖非负权）。
3. 用 `u` 去 **松弛** 它的邻居：若 `dist[v] > dist[u] + w`，就更新 `dist[v]`。
4. 重复直到终点被确定（或所有点处理完）。

“永久确定”这一步如果用朴素数组扫描是 O(N) 的，整体会退化成 O(N²)。
我们用 **优先队列（小根堆）** 代替线性查找，每次 O(log N) 取出最小点，得到 **堆优化 Dijkstra**。

## 数据结构

```cpp
vector<vector<pair<int,int>>> adj(n+1);  // 邻接表：adj[u] = {(v,w), ...}
vector<long long> dist(n+1, LLONG_MAX);  // 起点到各点的最短距离
priority_queue<pair<long long,int>,
               vector<pair<long long,int>>,
               greater<pair<long long,int>>> pq;  // 小根堆 (距离, 节点)
```

- **邻接表** 比邻接矩阵省空间（M 远小于 N² 时），且遍历邻居高效。
- **小根堆** 让 `(距离, 节点)` 按距离升序弹出，自动实现“每次取最小”。
- **dist 用 long long**：虽然本题数值不大，但加法 `d + w` 在极端数据下可能溢出 int，养成好习惯。

---

## 三个关键优化（务必理解）

### 1. 懒删除（lazy deletion）—— 最重要
一个节点可能在被更短路径多次“松弛”后 **多次入堆**。
堆里同一节点会存在多条记录（旧的、新的）。弹出时比较：

```cpp
if (d > dist[u]) continue;   // 堆里的旧记录，直接丢弃
```

只有“距离 == 当前最优 dist[u]”的那条才是有效的，其余都是过期的，跳过即可。
这样我们**不需要**真正从堆里删除元素，逻辑简单且正确。

### 2. 提前退出
第一次从堆中弹出终点 `end` 时，它的距离就是全局最短路（堆升序 + 非负权保证后面不会有更优解），可直接输出并结束，省去后续无用计算。

### 3. 小根堆 + 关闭同步
`ios::sync_with_stdio(false); cin.tie(nullptr);` 是读入优化的标配，配合堆的 O(log N) 弹出，轻松过题。

---

## 复杂度分析

- **时间**：每个节点入堆/出堆最多 O(M) 次（每条边最多触发一次松弛），每次堆操作 O(log N)
  → **O((N + M) log N)**。本题 N≤500、M≤5000，完全无压力。
- **空间**：邻接表 O(N+M)，dist 数组 O(N)，堆最坏 O(M)
  → **O(N + M)**。

---

## 易错点清单

1. **有向边只加一次**：`adj[u].push_back({v,w})`，不要写成双向。
2. **别漏懒删除判断** `if (d > dist[u]) continue;`，否则可能用过期的大距离去松弛邻居，得到错误答案。
3. **dist 初值用 LLONG_MAX**，且 `d + w` 前确认不会溢出（用 long long 最稳）。
4. **判不可达**：不要假设一定能到，堆空后要根据 `dist[end]` 是否为无穷大来决定输出 `-1`。本代码直接在堆空后输出 `-1`，简洁正确。
5. **非负权前提**：本题成立；若以后遇到负权，必须换算法。

## 完整代码

```CPP
#include <iostream>
#include <vector>
#include <queue>      // priority_queue
#include <climits>     // LLONG_MAX

using namespace std;

int main() {
    // 关同步 + 解绑 cin/cout，是卡常必备提速手段
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 邻接表存图：adj[u] 表示从 u 出发能“单向直达”的 (终点 v, 时间 w) 列表
    // 用 vector<vector<>> 比 list 缓存更友好，遍历更快
    vector<vector<pair<int, int>>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});   // 注意是单向边，只加一次
    }

    const int start = 1, end = n;

    // dist[i]：起点到 i 的“当前已知最短距离”。初始化为无穷大（不可达）
    // 用 long long 防加法溢出，初值取 LLONG_MAX
    vector<long long> dist(n + 1, LLONG_MAX);
    dist[start] = 0;

    // 小根堆（优先队列）：始终优先取出“目前距离最小”的节点
    // 元素为 (距离, 节点)。greater<pair<>> 让 first（距离）小的在堆顶
    priority_queue<pair<long long, int>,
                   vector<pair<long long, int>>,
                   greater<pair<long long, int>>> pq;
    pq.push({0, start});

    while (!pq.empty()) {
        // 取出当前距离最小的节点 u，距离记为 d
        auto [d, u] = pq.top();
        pq.pop();

        // 关键：懒删除（lazy deletion）
        // 一个节点可能被多次入堆（每次被更短路径松弛都会再 push 一次）。
        // 如果堆里这条记录的旧距离 d 比我们已知的最优 dist[u] 还大，
        // 说明它已经被更优的路径处理过了，直接跳过，避免重复且错误的松弛。
        if (d > dist[u]) continue;

        // 提前退出优化（依赖非负权）：
        // 第一次从堆中弹出终点 end 时，它的距离 d 必然就是全局最短路。
        // 因为堆是按距离升序弹出的，更小的候选都在后面，不可能再更新它。
        if (u == end) {
            cout << d << '\n';
            return 0;
        }

        // 松弛（relax）：用 u 去更新它所有邻居 v 的距离
        for (auto& [v, w] : adj[u]) {
            // 如果经过 u 到 v 比已知的更短，就更新并把这个新候选入堆
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }

    // 堆已空仍未到达终点 -> 起点与终点不连通
    cout << -1 << '\n';
    return 0;
}
```

## 一句话总结

把车站和单向公路建成**有向非负权图**，用 **堆优化 Dijkstra** 求 1→N 最短路；
靠 **懒删除** 保证正确性、**提前退出 + 小根堆** 保证效率，不可达输出 `-1`。这是最短路入门必会的模板题。
