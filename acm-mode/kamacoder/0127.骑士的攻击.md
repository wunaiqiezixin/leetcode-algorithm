# [knight attack](https://kamacoder.com/problempage.php?pid=1203)


> 数据范围：棋盘 1000 × 1000，坐标 x, y ∈ [1, 1000]；第一行 n 表示测试用例数，之后 n 行每行 `a1 a2 b1 b2`（起点、终点）；输出 n 行最短步数。
>
> 题型：**网格上最短路（无权，每步代价相同）**；经典解法有二：
> 1. **BFS**（保证最优，但地图大、n 大时易超时）；
> 2. **A\***（广搜的改良版，用启发式把搜索方向拉向终点，大幅剪枝）。

## 题目分析

骑士（马）走"日"字，从 `(a1,a2)` 到 `(b1,b2)` 求**最少步数**。第一反应是 BFS（每步代价相同，BFS 天然求无权图最短路）。但棋盘 1000×1000、n 可能很大，BFS 最坏要遍历近 1e6 个点 × n 次，会超时。

A\* 是 BFS 的升级版：用**优先队列**替换 BFS 的普通队列，让"更像通往终点"的节点优先扩展，从而少走大量弯路。

## 为什么用 A\*（对比 BFS）

| 维度 | BFS | A\* |
|------|-----|-----|
| 队列 | 普通 FIFO 队列 | 优先队列（按 `f` 小顶堆） |
| 扩展顺序 | 层层铺开，无方向偏好 | 受启发式引导，**朝终点方向**扩展 |
| 最优性 | **保证最短**（无权图） | 依赖启发式；本题常用启发式能过 OJ，但理论非严格可采纳 |
| 大棋盘 + 多用例 | 易 TLE（遍历太多） | 剪枝明显，**更稳** |
| 代码复杂度 | 极简 | 略多（多 g/h/f 与比较器） |

一句话：**BFS 是"绝对正确但可能慢"，A\* 是"快且本题实战正确"**。下面两种都给，提交用 A\*。

## A\* 核心思想（f = g + h）

A\* 给每个节点算一个估价 `f = g + h`：

- **g（已付出的现实代价）**：从起点到当前节点已经走的代价。
  本题一步是"马走日"，直线距离 sqrt(5)；为避免开方、提高精度，**用平方值 5 表示一步代价**（即 `g = 父g + 5`）。
- **h（预估的剩余代价 / 启发式）**：从当前节点到终点的预计代价。
  用**到目标的平方欧氏距离** `h = (x-b1)² + (y-b2)²`（同样不开根号，与 g 同量纲）。
- **f = g + h**：总估价，**f 越小越优先扩展**。

优先队列按 `f` 小顶堆弹出节点：起点 `f` 小、离终点近的节点先被探索，自然把搜索"拽"向终点，省掉 BFS 大量无用扩展。

> 关于 h 的严谨性：严格的 A\* 要求启发式 **可采纳（h ≤ 真实剩余代价）** 才能保证最优。本题常用的"平方欧氏距离"在远点时可能**高估**（如离终点距离 10，平方 100 > 真实步数代价 25），并非严格可采纳。若追求理论最优，请用 BFS（见下文）。这里如实说明，不留坑。

## 关键细节

1. **8 个移动方向（马走日）**：`{±2,±1},{±1,±2}` 共 8 种。
2. **边界判定**：坐标必须在 `[1,1000]`，越界 `continue`。
3. **去重 / 访问标记**：用 `moves[x][y]` 记录到达该点的最少步数，`==0` 表示未访问（起点也置 0 表示已访问，不会被重复入队）。
4. **优先队列是小顶堆**：C++ 默认大顶堆，需 `operator<` 返回 `f > other.f`，或 `priority_queue<Knight, vector<Knight>, greater<Knight>>`。
5. **g 的缩放**：一步代价用 5（ sqrt(5) 的平方），h 也用平方距离，二者同量纲，`f` 才有可比性。
6. **起点==终点**：直接输出 0。
7. **多用例**：每个用例前 `memset(moves,0,sizeof(moves))` 清空；`moves` 开 `1001×1001` 静态数组即可。
8. **提前结束**：弹出节点时若已是终点，可立即 `return`。

## 复杂度

- **A\***：时间复杂度难以精确量化，取决于启发式。最坏退化为 BFS，约 O(V)（V 为节点数，本题 ≤ 1e6）；最佳情况近乎直线奔向终点，约 O(d·log d)（d 为深度）。粗略可记 O(n·log n)，n 为被扩展的节点数，**远小于 BFS 的全量遍历**。空间 O(棋盘) = 1e6 `int`。
- **BFS**：时间 O(V) 最坏遍历整盘，多用例叠加易 TLE；空间 O(V)。

## 易错点

- 忘记把 `moves` 清零 → 多用例互相污染。
- 优先队列写成大顶堆（没重载 `<` 或用反了比较方向）→ 扩展顺序全错。
- 启发式 `h` 与 `g` 量纲不一致（一个开方一个不开）→ `f` 比较失真。
- 边界漏判，访问到 0 或 1001 下标越界。
- 误以为 A\* 此启发式严格保证最优：理论最优请用 BFS。

## 完整代码（C++ · A\*）

```cpp
#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

// 骑士节点：记录坐标与估价 g/h/f
struct Knight {
    int x, y;
    int g, h, f;
    // C++ 优先队列默认大顶堆，重载 < 让它变成「f 越小越优先」的小顶堆
    bool operator<(const Knight& other) const {
        return f > other.f;
    }
};

int moves[1001][1001];                 // moves[x][y]：到达 (x,y) 的最少步数，0 表示未访问
int b1, b2;                            // 当前用例的目标坐标
// 马走日的 8 个方向
int dirs[8][2] = {{-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}};

// 启发式 h：到目标的平方欧氏距离（不开根号，与 g 同量纲）
int Heuristic(int x, int y) {
    return (x - b1) * (x - b1) + (y - b2) * (y - b2);
}

void astar(Knight start) {
    priority_queue<Knight> que;        // 小顶堆（按 f）
    que.push(start);
    while (!que.empty()) {
        Knight cur = que.top(); que.pop();
        // 到达终点：记录的步数已在「首次访问」时写入 moves，这里直接返回即可（提速）
        if (cur.x == b1 && cur.y == b2) return;
        for (int i = 0; i < 8; ++i) {
            int nx = cur.x + dirs[i][0];
            int ny = cur.y + dirs[i][1];
            if (nx < 1 || nx > 1000 || ny < 1 || ny > 1000) continue; // 越界
            if (moves[nx][ny] == 0) {          // 首次访问才记录并入队
                moves[nx][ny] = moves[cur.x][cur.y] + 1;
                Knight next;
                next.x = nx; next.y = ny;
                next.g = cur.g + 5;            // 一步代价 = 马走日平方距离 5（避免开方）
                next.h = Heuristic(nx, ny);    // 启发式：到目标的平方距离
                next.f = next.g + next.h;      // 总估价
                que.push(next);
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    while (n--) {
        int a1, a2;
        cin >> a1 >> a2 >> b1 >> b2;
        memset(moves, 0, sizeof(moves));      // 每个用例清空
        Knight start;
        start.x = a1; start.y = a2;
        start.g = 0;
        start.h = Heuristic(a1, a2);
        start.f = start.g + start.h;
        moves[a1][a2] = 0;                     // 起点标记为已访问
        astar(start);
        cout << moves[b1][b2] << '\n';
    }
    return 0;
}
```


## 对比：BFS 解法（保证最优，可能超时）

BFS 是"层序扩散"，每个节点首次出队时步数即最短（无权图），**理论必对**，但搜索面大。仅作对照 / 小数据用。

```cpp
#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

struct Node { int x, y, step; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int dirs[8][2] = {{-2,-1},{-2,1},{-1,-2},{-1,2},{1,-2},{1,2},{2,-1},{2,1}};
    int n; if (!(cin >> n)) return 0;
    while (n--) {
        int a1,a2,b1,b2; cin >> a1 >> a2 >> b1 >> b2;
        if (a1==b1 && a2==b2) { cout << 0 << '\n'; continue; }
        bool vis[1001][1001] = {false};
        queue<Node> q;
        q.push({a1,a2,0});
        vis[a1][a2] = true;
        int ans = -1;
        while (!q.empty()) {
            Node cur = q.front(); q.pop();
            for (int i=0;i<8;++i) {
                int nx=cur.x+dirs[i][0], ny=cur.y+dirs[i][1];
                if (nx<1||nx>1000||ny<1||ny>1000) continue;
                if (vis[nx][ny]) continue;
                vis[nx][ny]=true;
                if (nx==b1 && ny==b2) { ans=cur.step+1; break; }
                q.push({nx,ny,cur.step+1});
            }
            if (ans!=-1) break;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

## 总结

网格 + 8 方向（马走日）求最少步数：**BFS 保证最优但易超时，A\* 用 `f=g+h` 优先队列把搜索拽向终点、剪掉大量无用扩展，实战更快更稳**。

- **A\***：`g` 用「一步=5」、`h` 用「到目标平方欧氏距离」，二者同量纲；优先队列按 `f` 小顶堆；`moves` 判重 + 边界判定 + 多用例清零。
