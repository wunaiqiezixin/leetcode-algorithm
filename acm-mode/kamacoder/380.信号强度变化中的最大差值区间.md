# [Signal Strength Peak Interval](https://kamacoder.com/problempage.php?pid=1460)

> 数据范围：0 ≤ n ≤ 1000，array[i] ≥ 0 .

## 动态规划 思路分析

本题需要在一个给定的数组中寻找“波峰区间”，并找出使得区间内峰顶最大值与两端最小值之差最大的区间。

一个“极大波峰区间”可以视为以某个元素作为峰顶 m，向左找到非递减序列的最左端点，向右找到非递增序列的最右端点。在这个最大的跨度范围内，区间最大值自然是 array[m]，而最小值则是两端点的值中较小的那个。极大化区间的跨度能确保两端的值尽可能地小，从而使差值 array[m] - min(左端点值, 右端点值) 尽可能大。

我们可以通过两趟遍历（类似动态规划思想）以 O(N) 的时间复杂度提前算出每个点向左、向右延伸的最远端点：

- **向左找左边界**：从左往右遍历数组，如果当前元素大于等于前一个元素，则它的左边界等于前一个元素的左边界；否则左边界就是它自己。
- **向右找右边界**：从右往左遍历数组，如果当前元素大于等于后一个元素，则它的右边界等于后一个元素的右边界；否则右边界就是它自己。

有了左右边界后，我们遍历每个元素作为峰顶，计算并维护全局最大的差值即可。

## 复杂度分析

- 时间复杂度：O(N)；
- 空间复杂度：O(N)。

## 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    // 优化输入输出
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int m;
    if (!(cin >> m)) return 0;
    if (m == 0) {
        cout << 0 << "\n";
        return 0;
    }
    vector<int> arr(m);
    for (int i = 0; i < m; ++i) {
        cin >> arr[i];
    }
    // 记录每个元素向左最多能延伸到的底端位置
    vector<int> left_bound(m);
    left_bound[0] = 0;
    for (int i = 1; i < m; ++i) {
        if (arr[i - 1] <= arr[i]) {
            left_bound[i] = left_bound[i - 1];
        } else {
            left_bound[i] = i;
        }
    }
    // 记录每个元素向右最多能延伸到的底端位置
    vector<int> right_bound(m);
    right_bound[m - 1] = m - 1;
    for (int i = m - 2; i >= 0; --i) {
        if (arr[i + 1] <= arr[i]) {
            right_bound[i] = right_bound[i + 1];
        } else {
            right_bound[i] = i;
        }
    }
    // 遍历每一个峰顶，寻找最大的差值
    int max_diff = 0;
    for (int i = 0; i < m; ++i) {
        int cur_min = min(arr[left_bound[i]], arr[right_bound[i]]);
        max_diff = max(max_diff, arr[i] - cur_min);
    }
    cout << max_diff << "\n";
    return 0;
}
```

## 第二个思路

第二种写法不显式找峰顶，而是直接在「单调段」上累计相邻差，空间只需常数个变量。关键在于：**任意一个波峰区间的最值差，等于它两段单调子区间之一的最值差**（左非递减子段差 = `array[m] − array[i]`，右非递增子段差 = `array[m] − array[j]`），所以「所有波峰区间的最大差 = 所有纯单调段的最大差」。于是只需前向求非递减段的最大跨度和 `l_max`、后向求非递增段的最大跨度和 `r_max`，取较大者即为答案。

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; ++i) cin >> arr[i];
    if (n <= 1) {
        cout << 0 << '\n';
        return 0;
    }
    int l_max = -1;
    int cur = 0;
    for (int i = 1; i < n; ++i) {
        int diff = arr[i] - arr[i - 1];
        if (diff >= 0) cur += diff;
        else cur = 0;
        l_max = max(cur, l_max);
    }
    int r_max = -1;
    cur = 0;
    for (int i = n - 1; i > 0; --i) {
        int diff = arr[i - 1] - arr[i];
        if (diff >= 0) cur += diff;
        else cur = 0;
        r_max = max(r_max, cur);
    }

    cout << max(r_max, l_max) << '\n';

    return 0;
}
```


## 一句话总结

波峰区间可退化到纯单调段，且其最值差等于两段单调子区间之一的最值差——思路一用两趟递推预处理左右边界（O(N) 空间），思路二直接沿单调段累计相邻差（O(1) 空间），二者等价、均 O(N)。
