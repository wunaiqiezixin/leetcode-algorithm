# [intercity cargo transport III](https://kamacoder.com/problempage.php?pid=1154)

> 数据范围：1 <= n <= 1000，1 <= m <= 10000，边权 v ∈ [-100, 100]；查询 `src dst k`
> 题型：**带边数限制的单源最短路**（Bellman-Ford 限制松弛轮数），等价 LeetCode 787「K 站中转内最便宜航班」
>区别：边权仍含负（Dijkstra 退役），但**多了「最多经过 k 个城市」的路径长度限制**，不再要求检测负权回路（因为限制轮数后即便有负环也不会死循环）。

## 题目分析

n 个城市、m 条**单向**道路，权值 `v = 运输成本 - 政府补贴`（可正可负）。
给定查询 `src dst k`，求从 `src` 到 `dst`、**最多经过 k 个城市**条件下的**最低运输成本**（可为负 = 盈利）。

输出分两种情况：

| 情况 | 输出 |
|------|------|
| 在 k 个城市限制内，src 能到 dst | 整数 `dist[dst]`（可负 = 盈利） |
| 限制内无法到达 | 字符串 `"unreachable"` |

> 关于「k 个城市」的精确语义：结合官方题解（代码随想录）与本题的等价模型（LC787），这里的 k 实际表示**最多 k 个中转城市（max stops）**，等价于**路径最多 k+1 条边**。因此 Bellman-Ford 只需**松弛 k+1 轮**。

## 为什么 Dijkstra 不行

边权含负 → Dijkstra 直接失效。只能用 Bellman-Ford（或 SPFA），并且要额外**限制边数**。

## 核心思想：Bellman-Ford + 边数限制（+ 关键快照）

普通 Bellman-Ford 每轮松弛时，如果直接用「本轮已更新的 dist」去更新后续边，会发生**链式松弛**——
一条边更新后，紧接着的下一条边又用它更新，等于**一轮之内偷偷走了多条边**，这就破坏了「最多 k+1 条边」的限制。

解决方式（本题的灵魂）：**每一轮开始，先把上一轮的 dist 复制成 `backup` 快照，所有松弛都用 `backup` 的值作为「起点侧距离」，只更新本轮的 `dist`**。
这样第 i 轮的结果严格只来自「第 i-1 轮的最短路 + 一条边」，即每轮恰好「多走一条边」。

```
dist[src] = 0;
for (轮数 i = 1 .. k+1):
    backup = dist;                 // 复制上一轮快照
    for (每条边 s->t, 权 v):
        if (backup[s] != INF && backup[s] + v < dist[t])
            dist[t] = backup[s] + v;   // 用快照更新，绝不读本轮刚改的 dist
```

松弛 `k+1` 轮后，`dist[dst]` 就是「最多 k+1 条边」下的最短路。若仍为 INF → `"unreachable"`。

> 复杂度：共 (k+1) 轮 × m 条边 → **O(k·m)**，k 与 n 同量级时约 1e7，稳过。

## 关键细节

1. **必须用 backup 快照**：这是「有边数限制」和普通 Bellman-Ford 的唯一本质差异，漏掉就会 WA（路径悄悄超边）。
2. **松弛 k+1 轮**：对应「最多经过 k 个城市（最多 k+1 条边）」。少一轮会漏掉合法更短路径，多一轮会放过超边路径。
3. **INF 防护**：`dist` 用 `long long + 1e18`，只从 `backup[s] != INF` 出发松弛，避免 `INF + 负数` 污染。
4. **提前退出**：某轮无任何更新即已收敛，可 `break`（负环场景下也能安全终止，不会死循环）。
5. **输出是字符串 `"unreachable"`**：注意大小写，不是 `-1`；可达时输出整数（可负）。

## 复杂度

- 时间：O(k·m)，k+1 轮每轮扫 m 条边，最坏 `(n)·(10000) = 1e7` 量级。
- 空间：边表 O(m)、dist / backup 数组 O(n) → **O(n + m)**。

## 易错点

1. **忘记 backup 快照**：直接 `if (dist[s] != INF && dist[s]+v < dist[t])` 用本轮 dist 更新 —— 链式松弛导致边数超限。
2. **轮数写错**：写成 k 轮（而非 k+1）会让「经过 k 个城市」少算一条边，漏掉正确路径。
3. **把 k 误解为边数**：题目说「k 个城市」，实际等价 k+1 条边；按 k 轮松弛会错。
4. **从 INF 出发的边参与松弛**：务必加 `backup[s] != INF` 判断。
5. **与 #1153 混淆**：本题**不需要负环检测**（限制轮数后天然不会死循环），别画蛇添足去判 circle。

## 完整代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 边表（有向、权值可负）：s->t，权值 v
    vector<int> s(m), t(m), v(m);
    for (int i = 0; i < m; ++i) {
        cin >> s[i] >> t[i] >> v[i];
    }

    int src, dst, k;
    cin >> src >> dst >> k;

    const long long INF = 1e18;          // 足够大，且 INF + v 不会溢出
    vector<long long> dist(n + 1, INF);
    dist[src] = 0;

    // 题目：最多经过 k 个城市 → 等价于最多 k+1 条边 → 松弛 k+1 轮。
    for (int i = 1; i <= k + 1; ++i) {
        // 关键：用上一轮的快照 backup 来更新本轮 dist。
        // 保证第 i 轮的结果只由“第 i-1 轮最短距离 + 一条边”得到，
        // 杜绝一轮内链式松弛、偷偷多走边，从而严格满足边数限制。
        vector<long long> backup = dist;
        bool updated = false;
        for (int j = 0; j < m; ++j) {
            // 只从可达点出发松弛；用 backup 而非 dist，避免本轮连锁更新
            if (backup[s[j]] != INF && backup[s[j]] + v[j] < dist[t[j]]) {
                dist[t[j]] = backup[s[j]] + v[j];
                updated = true;
            }
        }
        if (!updated) break;             // 已收敛，提前结束
    }

    if (dist[dst] == INF) {
        cout << "unreachable\n";
    } else {
        cout << dist[dst] << '\n';       // 可为负数（盈利）
    }

    return 0;
}
```

### 示例推演（加深理解）

输入：
```
6 7
1 2 1
2 4 -3
2 5 2
1 3 5
3 5 1
4 6 4
5 6 -2
2 6 1
2 6 1          <- 查询：src=2, dst=6, k=1（最多 1 个中转 = 最多 2 条边）
```
松弛 k+1 = 2 轮：
- 初始：`dist[2]=0`，其余 INF
- 第 1 轮（backup=初始）：从 2 出发更新 `dist[4]=-3, dist[5]=2, dist[6]=1`
- 第 2 轮（backup=第1轮结果）：`dist[5]=2` 经 `5->6(-2)` → `dist[6]=min(1, 2-2)=0`
- 结束，`dist[6]=0` → 输出 **0** （路径 `2->5->6`，1 个中转，成本 2+(-2)=0）

## 一句话总结

边权含负 → **Dijkstra 退役**，上 **Bellman-Ford**；但多了「最多 k 个城市」限制，
本质是**限制边数（k+1 条边）**。最关键的技巧是**每轮用上一轮快照 `backup` 更新**，
杜绝链式松弛超额；松弛 k+1 轮后 `dist[dst]` 即答案，仍为 INF 则输出 `"unreachable"`。
注意本题**不要**做负环检测（限制轮数后天然安全）。
