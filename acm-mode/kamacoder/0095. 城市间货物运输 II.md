# [intercity cargo transport II](https://kamacoder.com/problempage.php?pid=1153)

> 数据范围：1 <= n <= 1000，1 <= m <= 10000，边权 v ∈ [-100, 100]；**可能出现负权回路**
> 与「城市间货物运输 I」（pid=1152）的唯一区别：本题**不再保证无负权回路**，需要检测并适当处理。

## 题目分析

n 个城市、m 条**单向**道路，每条路权值 `v = 运输成本 - 政府补贴`（可正可负）。
求从城市 1 到城市 n 的**最小综合运输成本**（最短路径权值和，可为负 = 盈利）。

输出分三种情况，必须严格区分：

| 情况 | 输出 |
|------|------|
| 1 到 n 不可达 | 字符串 `"unconnected"` |
| 存在**能影响 1->n 路径**的负权回路 | 字符串 `"circle"` |
| 正常可达且无致命负环 | 整数 `dist[n]`（可为负 = 盈利） |

本题是 [intercity cargo transport I](./acm-mode/kamacoder/0094.城市间货物运输%20I.md) 的升级版：边权依旧含负 → **Dijkstra 依旧退役**；但多了「负权回路」这一陷阱——
一个总权值为负的回路，反复绕行会让路径成本无限下降/收益无限增大，因此必须检测。

## 为什么不能用 Dijkstra / 朴素 Bellman-Ford 不够

- **Dijkstra**：依赖非负权，有负权即失效（同 #1152）。
- **朴素 Bellman-Ford（只跑 n-1 轮）**：能处理负权，但**遇到负权回路会陷入死循环或给出错误无限值**——
  第 n 轮仍会不断松弛，距离一直变小，没有任何收敛点。所以必须在 n-1 轮后**额外做负环检测**。

## 核心思想：Bellman-Ford + 负权回路检测

1. **阶段一（求最短路）**：松弛 n-1 轮。一条不含回路的最短路径最多含 n-1 条边，
   因此 n-1 轮足以把所有可达点的最短距离“推”到位（可加“无更新则提前退出”优化）。
2. **阶段二（检测负环）**：再做第 n 轮——遍历所有边，若仍存在 `dist[u] != INF` 且
   `dist[u] + w < dist[v]` 的边，说明其终点 `v` 处于「负权回路影响链」上：
   从起点 1 可达，且经过负环可让它的距离无限减小。
3. **关键严谨点（易漏）**：不是所有负环都要输出 `"circle"`。
   若负环只在“从 1 可达但到不了 n”的孤立分支，它根本不影响 1->n 的最短路，
   应当**正常输出 `dist[n]`**。只有当受影响的点能**沿正向边到达 n** 时，负环才会“污染”1->n 的最短路，此时才输出 `"circle"`。
4. **判可达**：若 `dist[n] == INF`，说明 1 到 n 无路径 → `"unconnected"`。

> 复杂度：两阶段共 O(n·m) = 1e7，n≤1000、m≤10000 轻松通过。

## 关键细节

1. **INF 取值与溢出防护**：用 `long long` + `INF = 1e18`；只从 `dist[u] != INF` 的点出发松弛，
   避免 `INF + 负数` 这类无意义甚至溢出的运算。
2. **负环影响范围扩散**：用 `queue` 从所有 `inNegative` 点沿正向边 BFS，判断能否到达 n——
   这一步决定输出 `"circle"` 还是正常最短距离。
3. **三种输出顺序**：先判 `circle`（负环能到 n）→ 再判 `unconnected`（不可达）→ 最后输出 `dist[n]`。
   顺序不能乱：即便 n 不可达，只要负环能到 n 也要优先报 `circle`（题目语义：能无限赚补贴优先提示）。
4. **输出是字符串原样**：`"circle"` / `"unconnected"` 注意大小写，不要输出 `-1`。
5. **用 `long long`**：多个负权累加、且要避免 INF 运算问题，long long 最稳。

## 复杂度

- 时间：阶段一最多 (n-1) 轮 × m 条边，阶段二 1 轮 × m 条边 + 一次 O(n+m) BFS → **O(n·m)**，最坏 `1000 × 10000 = 1e7`。
- 空间：边表 O(m)、dist / 标记数组 O(n)、邻接表 O(n+m) → **O(n + m)**。

## 易错点

1. **漏掉负环检测**：只跑 n-1 轮，遇到样例中的 `1->2->3->1` 负环会 WA 或死循环。
2. **负环影响范围判断缺失**：朴素地“发现负环就输出 circle”在负环到不了 n 的测试点会 WA；
   必须确认负环能到达 n 才行（严谨版）。
3. **从 INF 出发的边不要松弛**：务必加 `dist[u] != INF` 判断。
4. **三种输出优先级**：circle > unconnected > 数值，顺序写错会错。
5. **边权范围含负**：建边 `w` 用 `int`，累加进 `dist` 用 `long long`。

## 完整代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    // 边表：Bellman-Ford 需要按“边”遍历；adj 用于负环影响范围的正向扩散
    vector<int> u(m), v(m), w(m);
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        cin >> u[i] >> v[i] >> w[i];     // 单向边 s->t，权值 v（可负）
        adj[u[i]].push_back(v[i]);
    }

    const long long INF = 1e18;          // 足够大，且 INF + w 不会溢出
    vector<long long> dist(n + 1, INF);
    dist[1] = 0;                         // 起点到自身距离为 0

    // ---- 阶段一：Bellman-Ford 松弛 n-1 轮，求出（假设无负环时）的最短路 ----
    for (int i = 1; i <= n - 1; ++i) {
        bool updated = false;            // 本轮是否发生过松弛
        for (int j = 0; j < m; ++j) {
            // 只从已可达点出发松弛；跳过 INF 避免 INF+w 溢出/误更新
            if (dist[u[j]] != INF && dist[u[j]] + w[j] < dist[v[j]]) {
                dist[v[j]] = dist[u[j]] + w[j];
                updated = true;
            }
        }
        if (!updated) break;             // 已收敛，提前结束（无负环时安全）
    }

    // ---- 阶段二：第 n 轮检测负权回路 ----
    // 若某条边还能被松弛，说明其终点 v 处于“负环影响链”上：
    // 从 1 可达、且经过负环可让它的距离无限减小。
    vector<bool> inNegative(n + 1, false);
    for (int j = 0; j < m; ++j) {
        if (dist[u[j]] != INF && dist[u[j]] + w[j] < dist[v[j]]) {
            inNegative[v[j]] = true;
        }
    }

    // 从所有受影响的节点沿正向边扩散，看是否能到达终点 n。
    // 能到达 → 负环能“污染”1->n 的最短路（可无限变小）→ 输出 "circle"；
    // 不能到达 → 负环在到不了 n 的孤立分支，不影响 1->n，正常输出 dist[n]。
    queue<int> q;
    vector<bool> vis(n + 1, false);
    for (int i = 1; i <= n; ++i) {
        if (inNegative[i]) { q.push(i); vis[i] = true; }
    }
    bool reachN = false;
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        if (cur == n) { reachN = true; break; }
        for (int nxt : adj[cur]) {
            if (!vis[nxt]) { vis[nxt] = true; q.push(nxt); }
        }
    }

    // 输出优先级：circle > unconnected > 数值
    if (reachN) {
        cout << "circle\n";
    } else if (dist[n] == INF) {
        cout << "unconnected\n";
    } else {
        cout << dist[n] << '\n';         // 可为负数（盈利）
    }

    return 0;
}
```

## 一句话总结

边权含负 → **Dijkstra 退役**，上 **Bellman-Ford**：n-1 轮松弛求最短路后，**第 n 轮再扫一遍边**——
若仍有边可松弛，则终点落在“负环影响链”上；用 BFS 确认其**能否到达 n**：
能到 → 输出 `"circle"`，到不了就按 `dist[n]==INF` 输出 `"unconnected"` 还是 `dist[n]`（可负）。
三种输出的优先级 `circle > unconnected > 数值` 千万别写反。
