## 题目描述

某个大型软件项目的构建系统拥有 N 个文件，文件编号从 0 到 N - 1。在这些文件中，某些文件依赖于其他文件的内容，这意味着如果文件 A 依赖于文件 B，则必须在处理文件 A 之前处理文件 B。

请编写一个算法，用于确定文件处理的顺序。

### 输入描述

第一行输入两个正整数 N, M，表示 N 个文件之间拥有 M 条依赖关系。

后续 M 行，每行两个正整数 S 和 T，表示 **T 文件依赖于 S 文件**（即 S 必须在 T 之前处理）。

### 输出描述

输出共一行，如果能处理成功，则输出文件顺序，用空格隔开。

如果不能成功处理（相互依赖，即有环），则输出 `-1`。

### 示例

```
输入：
5 4
0 1
0 2
1 3
2 4

输出：
0 1 2 3 4
```

### 数据范围

- `1 <= N <= 10000`
- `1 <= M <= 10000`

---

## 问题本质：拓扑排序

这道题是**拓扑排序的纯模板题**。

- 每个文件是一个**节点**
- 每条依赖关系是一条**有向边**：T 依赖 S → 边 `S → T`（S 在前，T 在后）
- 目标：找出一个合法的处理顺序，使得对于每条依赖 S→T，S 都排在 T 前面
- 如果图中有环（循环依赖），则不存在这样的顺序，输出 `-1`

> **拓扑排序定义**：把有向无环图（DAG）的所有节点排成一个线性序列，使得对于图中任意一条边 u→v，u 都排在 v 前面。有环的图不存在拓扑排序。

---

## 方法一：BFS + Kahn 算法（推荐）

### 核心思路

利用**入度**来逐步"剥离"节点：

1. 所有入度为 0 的节点，没有任何依赖，可以最先处理
2. 每处理一个节点，就把它指向的所有后继节点的入度减 1（相当于少了一个依赖）
3. 当某个节点的入度变成 0，说明它的所有依赖都处理完了，可以处理它了
4. 重复直到队列为空

如果最后处理的节点数 == 总节点数，说明无环，输出序列；否则有环，输出 -1。

### 算法步骤

1. **建图**：邻接表存图，同时统计每个节点的入度
2. **初始化队列**：所有入度为 0 的节点入队
3. **BFS 遍历**：
   - 队首节点出队，加入结果序列
   - 遍历它的所有后继节点，后继节点入度 -1
   - 入度变为 0 的后继节点入队
4. **判断结果**：结果序列长度 == N → 输出序列；否则 → 输出 -1

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    // 邻接表：adj[u] 存储 u 的所有后继节点（u 指向的节点）
    vector<vector<int>> adj(n);
    vector<int> inDegree(n, 0); // 每个节点的入度

    // 建图：T 依赖 S → 边 S -> T
    for (int i = 0; i < m; ++i) {
        int s, t;
        cin >> s >> t;
        adj[s].push_back(t); // s -> t
        inDegree[t]++;       // t 的入度 +1
    }

    // 队列：存放入度为 0 的节点
    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (inDegree[i] == 0) {
            q.push(i);
        }
    }

    vector<int> result; // 存储拓扑序列

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        result.push_back(u); // 处理 u，加入结果序列

        // 遍历 u 的所有后继节点
        for (int v : adj[u]) {
            inDegree[v]--;        // 后继节点少了一个依赖
            if (inDegree[v] == 0) {
                q.push(v);        // 依赖全处理完了，可以处理 v 了
            }
        }
    }

    // 如果结果序列长度 == n，说明是合法的拓扑排序
    if (result.size() == n) {
        for (int i = 0; i < n; ++i) {
            if (i > 0) cout << ' ';
            cout << result[i];
        }
        cout << '\n';
    } else {
        // 有环，无法拓扑排序
        cout << -1 << '\n';
    }

    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(N + M)，N 是文件数，M 是依赖数。每个节点入队出队一次，每条边遍历一次。
- **空间复杂度**：O(N + M)，邻接表 O(M)，入度数组和队列 O(N)。

## 方法二：DFS 后序遍历 + 反转

### 核心思路

DFS 遍历图，**后序**记录节点（等所有子节点都处理完了，再记录自己），最后把结果**反转**，就是拓扑序列。

为什么后序 + 反转 = 拓扑排序？

- DFS 后序的特点：一个节点的所有后继（子节点）都处理完之后，才会记录这个节点
- 也就是说，后序序列中，**子节点在前，父节点在后**
- 反转之后，就变成了**父节点在前，子节点在后** → 正好满足拓扑排序的要求

### 三种状态标记

和课程表那道题一样，需要三种状态来检测环：

| 状态 | 含义 |
|------|------|
| 0 | 未访问过 |
| 1 | 正在访问（在当前 DFS 递归栈中） |
| 2 | 已访问完成（整个 DFS 子树都遍历完了） |

如果在 DFS 过程中遇到状态为 1 的节点，说明有环。

### 算法步骤

1. **建图**：邻接表存储
2. **初始化访问数组**：全为 0
3. **对每个未访问的节点做 DFS**：
   - 标记当前节点为 1（正在访问）
   - 遍历所有邻接点：
     - 状态 0 → 递归 DFS，发现环则返回 false
     - 状态 1 → 发现环，返回 false
     - 状态 2 → 跳过
   - 标记当前节点为 2（访问完成）
   - **把当前节点加入结果序列**（后序位置）
4. **DFS 全部完成后**：
   - 如果有环 → 输出 -1
   - 无环 → 反转结果序列，输出
5. **注意**：如果图有多个连通分量，需要从每个未访问的节点都开始一次 DFS

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

/**
 * @brief DFS 后序遍历，同时检测环
 * @param adj 邻接表
 * @param visited 访问状态数组（0=未访问, 1=正在访问, 2=已完成）
 * @param result 存储后序遍历结果
 * @param u 当前节点
 * @return 无环返回 true，有环返回 false
 */
bool dfs(vector<vector<int>>& adj, vector<int>& visited, vector<int>& result, int u) {
    visited[u] = 1; // 标记为正在访问

    for (int v : adj[u]) {
        if (visited[v] == 0) {
            // 未访问过，递归深入
            if (!dfs(adj, visited, result, v)) {
                return false; // 子节点发现环，向上传递
            }
        } else if (visited[v] == 1) {
            // 遇到正在访问的节点 → 有环
            return false;
        }
        // visited[v] == 2 时直接跳过
    }

    visited[u] = 2;        // 标记为访问完成
    result.push_back(u);   // 后序位置：所有子节点处理完了，记录自己
    return true;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<vector<int>> adj(n);
    for (int i = 0; i < m; ++i) {
        int s, t;
        cin >> s >> t;
        adj[s].push_back(t); // s -> t
    }

    vector<int> visited(n, 0); // 0=未访问, 1=正在访问, 2=已完成
    vector<int> result;        // 存储后序遍历结果

    bool hasCycle = false;

    // 对每个未访问的节点做 DFS（处理多个连通分量）
    for (int i = 0; i < n; ++i) {
        if (visited[i] == 0) {
            if (!dfs(adj, visited, result, i)) {
                hasCycle = true;
                break;
            }
        }
    }

    if (hasCycle) {
        cout << -1 << '\n';
    } else {
        // 后序遍历结果反转，就是拓扑序列
        reverse(result.begin(), result.end());
        for (int i = 0; i < n; ++i) {
            if (i > 0) cout << ' ';
            cout << result[i];
        }
        cout << '\n';
    }

    return 0;
}
```

### 复杂度分析

- **时间复杂度**：O(N + M)，每个节点和每条边都只访问一次。
- **空间复杂度**：O(N + M)，邻接表 O(M)，访问数组 O(N)，递归栈最坏 O(N)。

## 两种方法对比

| 对比维度 | BFS + Kahn 算法 | DFS 后序 + 反转 |
|---------|----------------|----------------|
| 核心思想 | 入度为 0 就删，边删边记录 | 后序遍历，最后反转 |
| 序列生成方式 | 正向生成（直接就是拓扑序） | 反向生成（需要反转） |
| 空间结构 | 队列 | 递归栈 + 结果数组 |
| 栈溢出风险 | 无 | N 很大时有风险（本题 N=10000 可能栈溢出） |
| 实现难度 | 较直观 | 需要理解后序 + 反转的逻辑 |
| 适用场景 | 大多数情况首选 | 图规模较小或需要 DFS 框架时 |

> **注意**：本题 N 最大 10000，如果图是一条长链，DFS 递归深度会达到 10000，可能栈溢出。**实际提交建议用 BFS 方法**，更安全。

## 常见坑点

### 坑 1：边的方向搞反

题目说 "T 文件依赖于 S 文件"，意思是 S 必须在 T 之前处理。

```
T 依赖 S  →  先处理 S，再处理 T  →  边是 S → T
```

很多人搞反了，写成 `adj[t].push_back(s)`，结果拓扑序就反了。


### 坑 2：忘记处理多个连通分量

图可能不是连通的！必须对每个未访问的节点都启动一次 DFS（或 BFS 时入度为 0 的节点可能有多个，队列会自动处理）。

BFS 天然支持多连通分量（所有入度为 0 的都入队），DFS 需要写 for 循环遍历每个节点。

### 坑 3：DFS 忘记反转结果

DFS 得到的是后序序列，**必须反转**才是拓扑排序。

```
后序：子节点在前，父节点在后  →  反转后：父节点在前，子节点在后  =  拓扑序
```

### 坑 4：BFS 只看队列空不看数量

队列空了不代表所有节点都处理完了，可能有环导致部分节点永远入不了队。必须判断 `result.size() == n`。

## 手动模拟示例

### 示例：N=5, M=4, 边 = [0→1, 0→2, 1→3, 2→4]

```
图结构：
  0 → 1 → 3
  ↓
  2 → 4
```

**BFS 过程**：

| 步骤 | 队列 | 出队 | 入度变化 | result |
|------|------|------|---------|--------|
| 初始 | [0] | - | - | [] |
| 1 | [1, 2] | 0 | 1入度:1→0, 2入度:1→0 | [0] |
| 2 | [2, 3] | 1 | 3入度:1→0 | [0, 1] |
| 3 | [3, 4] | 2 | 4入度:1→0 | [0, 1, 2] |
| 4 | [4] | 3 | 无后继 | [0, 1, 2, 3] |
| 5 | [] | 4 | 无后继 | [0, 1, 2, 3, 4] |

result 长度 = 5 = N → 输出 `0 1 2 3 4`

**DFS 过程**（从 0 开始）：

```
dfs(0): 标记0=1
  dfs(1): 标记1=1
    dfs(3): 标记3=1
      3无后继 → 标记3=2, result=[3]
    返回 true
  → 标记1=2, result=[3, 1]
  dfs(2): 标记2=1
    dfs(4): 标记4=1
      4无后继 → 标记4=2, result=[3, 1, 4]
    返回 true
  → 标记2=2, result=[3, 1, 4, 2]
→ 标记0=2, result=[3, 1, 4, 2, 0]
返回 true
```

后序结果：`[3, 1, 4, 2, 0]`
反转后：`[0, 2, 4, 1, 3]` → 也是合法的拓扑序列（拓扑序不唯一）

## 总结

>
> 拓扑排序有两种经典实现方式。
>
> **第一种是 Kahn 算法，基于 BFS**：
> 先统计每个节点的入度，把所有入度为 0 的节点加入队列。然后不断从队首取出节点，加入结果序列，同时把它的所有后继节点的入度减 1，如果某个后继的入度变成 0 就入队。最后如果结果序列长度等于节点数，说明是合法的拓扑排序；否则图中有环。
>
> **第二种是基于 DFS 后序遍历**：
> 对图做 DFS，在后序位置（等所有子节点都处理完了）记录节点。因为后序序列中子节点在前、父节点在后，反转之后就变成父节点在前、子节点在后，也就是拓扑排序。DFS 过程中用三种状态（未访问、正在访问、已完成）来检测环，如果遇到正在访问的节点就说明有环。
>
> 两种方法时间复杂度都是 O(N + M)。BFS 方法没有递归栈溢出的问题，一般更推荐；DFS 方法代码简洁，适合小规模图。






> **一句话总结**：BFS 看入度，零入度就出队；DFS 走后序，反转才是拓扑序。
